## 6. §0 — 何が言えて、何が言えないか（誠実さ）

- **導出 vs 翻訳**：MA-4 で5類型は「対応表（翻訳）→ 導出（創発）」へ前進。ただし「盲目的クラスタリングで丁度5個出る」とは主張しない（プリセット5点での創発）。
- **未フィット**：係数は機構を表す記号であって観測値ではない。実データへの較正はしていない。
- **純血種なし**：実組織は層・局面ごとに動物相が混ざる。対応表は「どちらへ寄っているか」を読むレンズで、ラベル貼りの道具ではない。
- **操作化は設計段階**：操作化 docs は予測を「反証可能にする」設計であって、「反証した／係数を測った」ではない（妥当性未検証）。
- **延長 sim の限界**：各 MA は1機構の検証で万能性を主張しない。係数は機構のパラメータ（測定値でない）。
