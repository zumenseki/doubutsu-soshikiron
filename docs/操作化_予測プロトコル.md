# 操作化② — 予測を反証可能な測定プロトコルへ（H'）

> **役割**：[操作化_測定接続.md §4](操作化_測定接続.md) が「次の作業」として名指しした③——**小規模な介入（A/B・自然実験）での予測検証**——の受け皿。bcd doc が「パラメータ ↔ 観測代理の**静的写像**」（何で測るか）を立てたのに対し、本 doc は「その代理で**予測を反証可能にする動的プロトコル**」（どう試して、何が出たら間違いか）を立てる。対象は [橋渡し §7](橋渡し_対応表.md) の**4予測**。
>
> **§0 堅持（最優先）**：本 doc は **測定の設計**であって測定**結果**ではない。各プロトコルが依拠する「観測代理 → パラメータ」写像の妥当性は**未検証**（[操作化_測定接続.md §0](操作化_測定接続.md)）。係数は機構を表すパラメータで観測値ではない（[正本 §0](正本_ミクロ機構.md)）。ここでの価値は §0 の三点のうち②**非自明予測**を「反証可能な形」にまで降ろすこと——通俗経営論と分岐する帰結を、**原理的に否定できる観測**に紐づけること——に尽きる。プロトコルを実施したわけでも、効果を保証するわけでもない。

---

## 1. なぜ「予測の操作化」が要るか

理論の価値②は「非自明な予測」だが、予測は**反証可能な観測に紐づいて初めて科学的主張になる**。[橋渡し §7](橋渡し_対応表.md) の4予測は現状「通俗論と分岐する」までで止まっており、**何を観測したら間違いと分かるか**が未定義だ。bcd（[操作化_測定接続.md](操作化_測定接続.md)）は痕跡→パラメータの写像表を立てたが、その §4 自身が「次の作業＝(1)操作的定義 (2)三角測量 (3)A/B・自然実験での予測検証」を**先送り**にした。本 doc はこの3点を、4予測それぞれについて具体化する。

**到達目標は「実施」でなく「反証可能性の担保」**：各予測に対し「この観測が出たら予測は誤り」と言える設計を与えるところまで。実データ収集・統計的検出力・係数推定は範囲外（§8 限界）。

---

## 2. 共通フォーマット（各予測を6項で降ろす）

各予測（§3〜§6）を、次の6項で記述する。**反証条件を必ず明記**するのが本 doc の主眼。

| 項 | 中身 | なぜ要るか |
|---|---|---|
| **① 機構的主張** | どの式・定理から落ちるか（正本の該当箇所） | 予測の出所を式に固定（誇張防止） |
| **② 操作的定義** | 独立変数・従属変数を**観測可能な手続き**で定義 | 「統制可能性」「内発」等の抽象語を計数可能に |
| **③ 観測代理（三角測量）** | [bcd §2](操作化_測定接続.md) の代理を**1パラメータ＝複数指標**で | 単一指標は交絡（§7）。三角で識別 |
| **④ 実験デザイン** | A/B（前後・群間）か自然実験か。割付・比較の単位 | 相関でなく分岐を見るため |
| **⑤ 反証条件** | **何が出たら予測は誤りか**（事前登録すべき棄却域） | 反証可能性の核。後付け解釈を封じる |
| **⑥ 交絡と限界** | 対抗仮説・測定の妥当性リスク | §0 の誠実さ（測れていない物を明示） |

> **設計原則（全予測共通）**：(a) **分岐を見る**——通俗論（動機＝1ダイヤル）の予測と本理論の予測が**逆符号・不連続**になる点を測る。(b) **介入で識別**——観察だけでは交絡が解けない代理は、小さな介入の前後比較で因果方向を絞る。(c) **事前登録**——反証域を観測前に決める（グッドハート・観測者効果の対策は §7）。

## 3. 予測1 — 統制可能性の不連続

**①機構的主張**：[正本 §7 最も鋭い反証可能予測](正本_ミクロ機構.md)＋[定理B](正本_ミクロ機構.md)。同じ強度の罰でも、**統制可能**（明確な改善路がある）なら適応的回避、**統制不能**（恣意的）なら無力感（Ĝ崩落）。両者は連続的グラデーションでなく**質的な不連続**を示すはず。効くのは「厳しさ」でなく「コントロールできるか」。

**②操作的定義**
- *独立変数 = 罰の統制可能性*：叱責・減点の事象を2軸で別々にコード化する。**強度**（声量・公開性・頻度のスコア）と**統制可能性**＝「叱責に**明示の改善路**（次に何をどうすれば回避できるか）が伴ったか」（伴=可制御／伴わず＝恣意=不能）。両軸を独立に評価者2名で行動コーディング（κ一致率を報告）。
- *従属変数 = 適応 vs 無力感*：当該行動領域での **(a) 改善着手率**（叱責後N日内に当該領域で新しい対処を試みた割合）、**(b) 撤退ラッチ**（当該領域での発言・提案・報告の停止）、**(c) 般化**（無関係領域へ「やっても無駄」が波及したか）。

**③観測代理（三角測量）**——[bcd §2](操作化_測定接続.md) より：
- Ĝ ← 自発的提案・改善着手率（順）／「やっても無駄」発言頻度（逆）／撤退ラッチ＝行動停止
- g ← 叱責領域での成功後の行動継続率／外部帰属（「運/上司」）の比率（逆）
- *識別*：**強度を一定にして統制可能性だけを変えた**サブサンプルで (a)(b)(c) を比較。3代理が**同方向に割れる**（可制御群で着手↑・ラッチ↓・般化なし／不能群で逆）なら Ĝ 仮説、割れなければ単なる強度効果。

**④実験デザイン**
- *第一選択 = A/Bフィードバック枠組み*：同一の是正内容を、**改善路つき**（「次回は X を Y に」）と**改善路なし**（評価のみ「ダメだ」）で群分け（チーム単位・割付を事前登録）。強度・伝達者・対象ミスは揃える。アウトカム＝②(a)(b)(c) を数週間追跡。
- *自然実験*：恣意的な評価制度（基準非公開の相対評価）→ 基準公開（可制御化）へ**制度変更した部署**の前後で②を測る（差分の差分・統制部署と比較）。

**⑤反証条件**（事前登録）
- 統制可能性を変えても②(a)(b)(c) が**強度の連続関数としてしか動かない**（可制御/不能の境界で**段差が出ない**）→ 予測1は**反証**。
- あるいは不能群で着手率が下がらない／般化（「やっても無駄」の波及）が起きない → 定理B 由来の「不連続・般化」部分は**反証**。
- 逆に、強度を揃えてなお可制御群と不能群が**離散的に分離**し、不能群でのみ般化が出れば**支持**（証明でなく一事例の整合）。

**⑥交絡と限界**
- *交絡*：可制御フィードバックは往々にして**口調も穏やか**（強度と相関）→ 強度コーディングで統制し、強度マッチしたペアでのみ比較。
- *逆因果*：もともと無力な個体ほど恣意的に扱われる（選択効果）→ 制度変更の自然実験（割付が個体特性に依らない）で緩和。
- *妥当性*：「改善着手」を自己申告でなく**行動痕跡**（提案ログ・試行回数）で取る（観測者効果は §7）。Ĝ は介入（小さな成功機会）への反応で無関心と弁別（[bcd §2 識別の注意](操作化_測定接続.md)）。

## 4. 予測2 — 撤回は据付より危険

**①機構的主張**：[定理A（報酬撤回＝罰）](正本_ミクロ機構.md)。u は参照点依存で κ>1。一度据えた報酬を ρ 未満へ下げると δ は負かつ**κ倍に増幅**され、恐怖系（τ↓・回避学習）を呼ぶ。→ 報酬の撤回・相対減額は「baseline に戻る」ではなく**別カテゴリの破壊**。「維持できない報酬は据えるな」。

**②操作的定義**
- *独立変数 = 報酬経路*：同額の最終報酬に至る2経路を比較する。**(撤回経路)** 一度高い報酬／手当を据えた後に ρ 未満へ減額・廃止／**(未据付経路)** 初めからその低水準。**鍵は最終水準を揃え、履歴だけを変える**こと。
- *従属変数 = 破壊の大きさ*：減額後（または同時点）の **(a) 離職・異動希望**、**(b) τ↓代理**（試行・提案の減少）、**(c) 回避行動**（当該業務の最小限化・サボタージュ）。「未据付群との差」が定理Aの主張する**増幅**。

**③観測代理（三角測量）**——[bcd §2](操作化_測定接続.md) より：
- κ ← **減給・降格への反応の強さ ÷ 同額の昇給への反応の強さ**（比として推定。1を超えるほど損失回避）
- ρ（参照点）← 直近に常態化した報酬水準（手当の据置期間で代理）／ω（[bcd §2](操作化_測定接続.md)）で自己基準か他者比較かを切り分け
- τ ← 新しいやり方の試行率・改善実験の本数（減）
- *識別*：撤回群の反応 ÷ 未据付群の反応 が**>1（できれば κ の独立推定値と整合）**なら定理A 支持。等倍なら「水準だけが効く」通俗論側。

**④実験デザイン**
- *自然実験（第一選択）*：**手当・賞与の改定**を使う。コロナ手当・繁忙手当・据置昇給などが**廃止/減額された部署**（撤回群）と、同水準だが**もともと無かった部署**（未据付群）を、改定前後の差分の差分で比較。最終報酬水準をマッチング。
- *A/B*：制度上難しいので**ビネット実験**（同職務記述で「昨年比減」vs「初年度から同額」を提示し、就業継続意図・努力配分を測る）を補助に。行動データの自然実験を主、ビネットを傍証に。

**⑤反証条件**（事前登録）
- 最終水準を揃えたとき、撤回群と未据付群の②(a)(b)(c) に**有意差が出ない**（履歴が効かない）→ 予測2は**反証**。
- 減給反応 ÷ 昇給反応 ≈ 1（κ≈1）→ 損失回避の増幅が無い＝定理Aの核は**反証**。
- 逆に撤回群が未据付群より明確に悪化し、その比が κ の独立代理と同オーダーなら**支持**。

**⑥交絡と限界**
- *撤回の理由*：手当廃止は**業績悪化と同時**に起きやすい（悪い知らせと交絡）→ 業績ショックが同等だが手当履歴が違う部署対で識別、または外生的な制度一律改定を使う。
- *予期可能性*：予告ありの減額は δ が小さい（定理Aは「予期されない/参照点割れ」で最大）→ 予告の有無を共変量に。
- *妥当性*：κ を昇給/減給の**行動反応比**で測るのは文脈依存（[bcd §2](操作化_測定接続.md)）。比として、同一集団・近接時期で推定。

## 5. 予測3 — 危険な役割ほど金銭は逆効果

**①機構的主張**：[定理C（アンダーマイニング罠）](正本_ミクロ機構.md)。f が x_ext より速く立ち上がる領域で `dR_eff/dR_ext < 0`。内在価値の高い（I₀大）役割では、関与への**顕著な金銭報酬が実効動機を下げうる**。安全な報酬形態は情報的・予期せぬもの（f≈0）。これは集団伝播でなく**単一エージェントの置換**（[橋渡し 一致⑥](橋渡し_対応表.md)・[応用_動機の締め出し.md](応用_動機の締め出し.md)）。

**②操作的定義**
- *独立変数 = 報酬の種類×顕著性*：同じ業務への報酬を **(統制的・有形・予期)** ＝ 金額明示の出来高 vs **(情報的・予期せぬ)** ＝ 事後の承認・裁量付与、で割付。**金額の大小でなく f を上げる形態か否か**が操作対象（[正本 修正項3](正本_ミクロ機構.md)）。
- *従属変数 = 実効動機*：**報酬と無関係な関与**——(a) 無報酬時間での自発的継続、(b) 質的な深さ（手抜き可能な場面での丁寧さ）、(c) 報酬撤去後の持続。金銭群でこれらが**下がる**のが定理Cの符号反転。
- *モデレータ = I₀（役割の内在価値）*：高 I₀ 役割（裁量的・意味づけの語りが豊富）と低 I₀ 役割（定型）で**効果が逆転**するか。

**③観測代理（三角測量）**——[bcd §2](操作化_測定接続.md) より：
- f ← **金銭報酬の導入前後での自発的関与の変化**（介入前後比較が要る）
- I₀ ← 報酬と無関係な関与／職務への意味づけの語り（自己申告バイアスに注意）
- *識別*：f は前後比較、I₀ は事前のベースライン。**高 I₀ 群でのみ金銭導入後に自発的関与↓**なら定理C 支持。低 I₀ 群では下がらない（むしろ系1/系2の随伴問題が主）。

**④実験デザイン**
- *A/B（前後×群間）*：高 I₀ と低 I₀ の役割それぞれで、金銭インセンティブ**導入群／非導入群**を作り、**導入前のベースライン自発関与**を取ってから前後差を比較（差分の差分）。アウトカムは無報酬文脈の行動（②(a)(c)）。
- *撤去フェーズ*：定理Cの核は「外発が内発を**置換**」＝撤去しても内発が戻らない。**インセンティブ撤去後**の自発関与を追い、金銭群が非導入群を下回るか（置換の残存）を見る。

**⑤反証条件**（事前登録）
- 高 I₀ 群でも金銭導入で自発的関与・無報酬時の継続が**下がらない（または上がる）**→ 予測3は**反証**（単純な加算的動機）。
- 撤去後に金銭群の内発が**速やかに回復**し非導入群と差が消える → 「置換」でなく一時的効果＝定理Cの置換主張は**反証**。
- I₀ による**交互作用が無い**（高低で同じ方向）→ 「危険な役割ほど」の条件部は**反証**。
- 逆に高 I₀ 群でのみ符号反転＋撤去後も残存 なら**支持**。

**⑥交絡と限界**
- *金額の交絡*：少額金銭は「侮辱」効果で別経路に効く（Gneezy-Rustichini 系）→ 形態（統制的/情報的）と金額を分離設計。
- *I₀ 測定*：意味づけの語りは社会的望ましさバイアス（[bcd §2](操作化_測定接続.md)）→ 行動代理（無報酬時間の関与）を主、語りを従に。
- *倫理/実務*：高 I₀ 役割で「あえて内発を壊す」介入は不可。**自然発生する制度導入**（新インセンティブ制度のロールアウト）を観察するのが現実的。
- *境界*：定理Cは「f が速く立ち上がる領域」限定。低 I₀・随伴不全（系1）の組織では報酬追加が正に効く——**全領域で報酬が逆効果という主張ではない**（§0）。

## 6. 予測4 — 恐怖は3チャネル同時劣化

**①機構的主張**：[定理D（恐怖の複合コスト）](正本_ミクロ機構.md)。恐怖は **τ↓（視野狭窄）・k↑（近視眼）・習慣化（目標志向→習慣）を同時に**起こす。一軸の「やる気が下がる」ではなく**独立3チャネルの劣化**＝縮んだ行動集合上での局所最適ロックイン。通俗論（恐怖＝モチベ低下という単一スカラー）と分岐する核心は「**3チャネルが共に動く**」点。

**②操作的定義**
- *独立変数 = 恐怖／脅威の点灯*：脅威手がかり（雇用不安・懲罰の顕著化・監視強化・失敗の高コスト化）をコーディング。急性（イベント）か慢性かも記録（[正本 §7](正本_ミクロ機構.md) 4条件の「急性/慢性」）。
- *従属変数 = 3チャネルを別々に*：
  - **τ↓**＝試行された選択肢の幅・新手法の採用率・改善実験の本数
  - **k↑**＝短期成果への偏り・**予防保全/長期投資の先送り率**（割引の代理）
  - **習慣化**＝**結果価値が下がっても続ける routine の残存**（outcome devaluation 非感受性／Adams-Dickinson 型＝もう報われない手順をやめるまでの遅延）
- *核の検定量*：脅威点灯で**3チャネルが共変動するか**（単一恐怖因子に乗るか）。

**③観測代理（三角測量）**——[bcd §2](操作化_測定接続.md) より：
- τ ← 新しいやり方の試行率／選択肢の幅／改善実験の本数
- k ← 短期成果への偏り／長期投資・予防保全の先送り率
- 習慣化 ← （bcd 表に直接項なし）→ 「報われなくなった手順の停止遅延」を新規代理に。恐怖指数 ← **ミス報告率（逆）**（[bcd §2 粗い対応](操作化_測定接続.md)）
- *識別*：脅威の前後で τ・k・習慣の3代理を測り、**共通の恐怖因子**に負荷が乗るか（因子分析／3者の相関上昇）を見る。単一「努力」スカラーで**3者の共変動が説明し尽くされない残差構造**があれば定理D の「直交3チャネル」を支持。

**④実験デザイン**
- *自然実験（第一選択）*：**脅威イベント**（人員削減発表・監視制度の厳格化・重大事故後の処罰強化）の前後で、同一チームの τ・k・習慣3代理を時系列で測る（割込み時系列・統制部署と差分の差分）。急性→慢性の遷移で Ĝ崩落（定理B）への接続も観測可能。
- *A/B*：脅威フレーミング（高ストークス vs 低ストークスの課題提示）を群間操作し、直後の探索幅・割引・devaluation 非感受性を計測（実務では倫理制約大＝主に自然実験）。

**⑤反証条件**（事前登録）
- 脅威点灯が **3チャネルのうち1つしか動かさない**（例：努力量は下がるが τ・k・習慣は不変）→ 「同時複合」は**反証**＝恐怖は単一動機軸。
- 3代理が**互いに無相関**（共通因子に乗らない・バラバラに動く）→ 「直交3チャネルが共に劣化」の**共変動**部分は**反証**。
- 単一の汎用「努力／モチベ」因子を統制すると**3チャネルの脅威効果が消える**→ 定理D の独立性は**反証**。
- 逆に脅威で3代理が共上昇（劣化）し、汎用努力因子を超える恐怖因子に乗れば**支持**。

**⑥交絡と限界**
- *τ↓ vs I₀↓ の交絡*（[bcd §2](操作化_測定接続.md) 既知）：探索の減少は恐怖（τ↓）とも無関心（I₀↓）とも読める→ **急性脅威操作**（無関心は急性で動かない）＋小さな成功機会への反応で弁別。
- *努力共通原因*：3チャネルが「単にやる気が下がった」の派生でないことを、汎用努力を統制した残差で示す必要（上の反証条件3）。
- *習慣化の測定*：devaluation 非感受性は実験室寄り。現場代理（報われない手順の停止遅延）は制度的硬直と交絡→ 個人/チーム単位の手順変更ログで近似。
- *方向*：定理D は恐怖→3チャネルの因果を主張。自然実験のイベント外生性が弱いと逆因果（低調なチームが脅威対象に選ばれる）が残る→ 割付の外生性を吟味。

## 7. 横断 — 三角測量と交絡の識別戦略（4予測共通）

[bcd §4](操作化_測定接続.md) が指摘した「指標→パラメータは多対多（交絡）」を、4予測すべてが共有する。共通の識別戦略を一箇所に：

**(A) 1パラメータ＝複数代理（三角測量）**：単一指標は必ず別読みできる。同一パラメータを**最低2〜3の独立代理**で測り、**同方向に動くか**を見る（各予測③）。割れたら測れていない（[bcd §2](操作化_測定接続.md)）。

**(B) 交絡の定番ペアと割り方**（本理論で繰り返し出る）：

| 紛らわしい対 | どちらも説明する観測 | 割る手 |
|---|---|---|
| τ↓（恐怖） vs I₀↓（無関心） | 提案・試行の減少 | **急性脅威操作**＋小さな成功機会への反応（無関心は反応薄／恐怖は脅威除去で戻る） |
| Ĝ低（無力感） vs 無関心 | 「やっても無駄」発言・行動停止 | 介入（確実に勝てる小成功）への反応で弁別（[bcd §2](操作化_測定接続.md)） |
| 損失回避κ vs 単なる水準効果 | 減額後の悪化 | **最終水準をマッチ**し履歴だけ変える（予測2④） |
| 恐怖の複合 vs 単一努力低下 | 成果の全般的低下 | 汎用努力因子を統制した**残差に3チャネル構造**が残るか（予測4⑤） |

**(C) 観察では足りない所は介入で**：逆因果・選択効果が残る代理は、**小さな前後比較（A/B）か制度変更の自然実験**で因果方向を絞る。自然実験は外生性が命（イベントが個体特性で割り付かない）、A/B は倫理・実務制約が命（高 I₀ 役割で内発を壊す介入や強い脅威操作は不可＝**自然発生する制度ロールアウトの観察**が現実解）。

**(D) グッドハート／観測者効果**（[bcd §4](操作化_測定接続.md) の妥当性リスク）：
- *グッドハート*：「提案数」「ミス報告率」を目標値にすると、指標が**操作対象**になり代理性が壊れる（報告を増やすために軽微報告を水増し 等）。→ 指標は**観測専用**にし KPI化しない。複数代理の**整合崩れ**を異常検知に使う。
- *観測者効果*：測られていると行動が変わる→ 自己申告でなく**既存業務に内在する行動痕跡**（提案ログ・試行回数・手順変更履歴・予防保全の実施記録）を主に。
- *事前登録*：反証域（棄却ライン）を**観測前に固定**し、後付けの「やっぱり支持」を封じる（各予測⑤）。

## 8. §0 — このプロトコルの限界（何を担保し、何を担保しないか）

**担保する**：4予測それぞれに「**何を観測したら予測は誤りか**」を与え、原理的な反証可能性を明示した（価値②の最終段）。各予測が通俗論（動機＝1ダイヤル）と**逆符号・不連続・交互作用**で分岐する点を測定対象に据えた。

**担保しない（重要）**：
1. **写像の妥当性は未検証**：すべての代理は「観測代理 → パラメータ」の**写像仮説**であり、その指標が本当にそのパラメータを測れているかは未検証（[bcd §0](操作化_測定接続.md)・[正本 §0](正本_ミクロ機構.md)）。本 doc はその仮説の上に**反証設計**を重ねたもので、土台が未検証である事実は変わらない。
2. **データは取っていない**：実施・収集・統計的検出力・効果量・係数推定はすべて範囲外。これは**設計図**であって結果ではない。
3. **一致は証明でない**：仮にプロトコルが予測を支持しても、それは機構との**整合の一事例**であって「係数を当てた」ことにはならない（consilience＝到達域の傍証・[橋渡し §0/§1](橋渡し_対応表.md)）。誇張は理論を弱める。
4. **倫理・実務の境界**：高 I₀ 役割で内発を壊す介入、強い脅威の人為操作は実施しない。自然実験（制度変更・イベント前後）が現実的経路で、その分**外生性の吟味**が常に要る。
5. **適用域限定**：各予測は条件付き（定理C＝f が速い領域のみ／恐怖の正当域＝[正本 §7](正本_ミクロ機構.md) の四重積集合）。「全領域で報酬が逆効果」「恐怖は常に悪」のような無条件主張ではない。

> **位置づけのまとめ**：[操作化_測定接続.md](操作化_測定接続.md)（静的写像＝何で測るか）→ 本 doc（動的プロトコル＝どう試し何で否定するか）→ 実施・検証（未着手・将来）。この鎖の**第二環**までを本 doc が担う。
