# Layer1 正本 — ミクロ機構（行動神経科学に基づく形式的学習機構）

> **この doc の役割**：二層理論の **Layer1（正本・厳密・機構）**。組織現象を、個体エージェントの学習動態として方程式で記述する。Layer2（比喩・5類型）はこの上に乗り、両者の写像は [橋渡し_対応表.md](橋渡し_対応表.md) にある。
> **読む順**：本 doc（機構）→ 橋渡し（写像）→ 比喩（発信層）。

---

## 0. 認識論的身分（最優先・必ず保持）

これは「組織データで係数が当たっているモデル」**ではない**（当たっていない）。価値は次の3点：

1. **内的整合性** — 諸主張が一つの機構から矛盾なく導かれること
2. **非自明な予測の導出** — 通俗的経営論（動機づけを1本のダイヤルと見る立場）と分岐する、検証可能な帰結を出せること
3. **隠れた前提の可視化** — 「報酬を増やせば効く」式の暗黙仮定を、式の上で明示・反証できること

係数は観測値ではなく **機構を表現するためのパラメータ**。この身分を曖昧にしない。誇張・過剰主張は理論を弱める。

## 1. 中心テーゼ

中心にある過程は **学習**。恐怖と報酬はそれを駆動する **非対称で直交した二つのエンジン** であり、異なる種類の行動・学習を生む。

- **報酬／SEEKING系** ＝ 自己修正的。接近行動はその後もサンプリングを続けるため、フィードバックが入り続け方策が更新され続ける。広い・審議的（目標志向）・探索的。
- **恐怖系** ＝ 自己封止的。回避行動は一度成功すると当の状況を二度と経験しないため、更新も消去もされない（データを自ら遮断する）。狭い・反射的（習慣的）・持続的な傷を残す。

→ 両者は「同一軸の強弱」ではなく、別の脳システムを動かし逆の行動を出力する。

---

## 2. 一次概念（プリミティブ）

- **エージェント**：状況→行動の写像（方策 π）を、経験した結果から更新し続ける学習主体
- **方策 π**：そのエージェントが現に学習した「この状況ではこう動く」の集合
- **随伴構造 C**：行動が結果（報酬・罰・無）に結びつく写像 — マネージャーが握る第一の制御面
- **情動文脈 A**：学習と行動が起きるときの覚醒・情動の状態（どのエンジンが、どの強度で点いているか）— 第二の制御面

組織 ＝ **多エージェント強化学習系**。経営者が設計できるのは C と A だけで、π そのものは触れない。各エージェントは「言われた C」ではなく **「経験した C」** から π を学ぶ。ここが全理論の出発点。

---

## 3. 基礎機構（キーストーン）

学習の本体は **随伴性 × 予測誤差**。動物学習のレスコーラ＝ワグナー・モデルを背骨にする。

```
ΔV = η · δ
δ  = R − V
```

- `V(s,b)` ＝ 状況 s で行動 b に割り当てた期待価値
- `δ` ＝ 予測誤差（これを巡ってのみ学習が起きる。δ=0 なら学習なし）
- `η` ＝ 学習率（旧 α·β を一本化。手がかり・結果の顕著性を束ねる）, η∈(0,1]
- `R` ＝ 随伴構造が実際に渡す結果

時間的近接（contiguity）だけでは不十分で、行動が結果を **予測する関係（随伴 / contingency）** が要る（Rescorla）。ドーパミン＝報酬予測誤差（Schultz）が δ の神経実装にほぼ対応する。

**基礎機構から落ちる二つの失敗様式（系）：**

- **系1（非随伴）**：全員一律のボーナス → 行動と結果が結びつかない → ΔV≈0。何も教えない。
- **系2（完全予測）**：毎年同額の昇給 → δ≈0。動機づけの力を構造的に失う。

→「報酬を増やしたのに効かない」の大半は額の問題ではなく、誤差と随伴の問題。

## 4. ヒト修正項（基礎機構に足す4項）

ネズミ理論で終わらせないための、明示的な修正項。曖昧な但し書きではなく式に組み込む。

### 修正項1：帰属ゲート `g`

ヒトは生の δ では更新しない。「この結果は自分の行動が起こしたのか」という因果帰属で重みづける。

```
δ_eff = g · δ
g = 知覚P(結果|行動) − 知覚P(結果|非行動)   # 主観化した随伴性 ΔP, g∈[0,1]
```

統制不能が続くと、特定の g だけでなく **一般化された統制可能性の信念 Ĝ が広域で崩落** する（＝ 学習性無力感 / Seligman-Maier）。Ĝ は行動を起こして初めて更新されるので、行動が止まれば Ĝ は永久に回復しない（§1の自己封止が再登場）。

### 修正項2：参照点依存 `κ, ρ`

学習に入るのは絶対量 R ではなく参照点からの差。損失は利得より重い（Brosnan-de Waal のオマキザル実験 ＋ プロスペクト理論）。

```
u(R; ρ) = (R − ρ)          if R ≥ ρ
        = κ · (R − ρ)      if R <  ρ     # κ > 1（損失回避）
ρ = ω · E_自己 + (1−ω) · 結果_他者         # 参照点は社会的に決まる, ω∈[0,1]
```

### 修正項3：内発的動機の置換 `I₀, f`

内在価値を持つ行動（SEEKING系が活動それ自体を報酬にする）では、総動機は外発＋内発の足し算ではない。顕著な外発報酬は内発を **置換** しうる。

```
R_eff = D(t) · (w · x_ext) + I₀ · (1 − f)
```

`f` ＝ 内在価値の抑制関数。報酬が **有形・予期され・統制的** なとき f は大、**情報的・予期せず・有能感を伝える** とき f≈0（Deci-Koestner-Ryan のメタ分析）。置換される I₀ は、本来「広く自己修正的に学習する良いモード」だった当の SEEKING系。

### 修正項4：象徴的・遅延報酬 `x, w, k`

ヒトの報酬は物質だけではない。地位・所属・有能感・意味が結果ベクトル `x` の正式な成分で、重み `w` は個人ごとに違う（単一の報酬ダイヤルが効かない理由）。遅延報酬は双曲割引で入る。

```
D(t) = 1 / (1 + k · t)     # 象徴的報酬は k が低い（長期でも価値を保つ）
```

## 5. 統合：ヒトの更新則（マスター方程式）

```
V ← V + η · g · ( u(R_eff; ρ) − V )
R_eff = D(t) · (w · x_ext) + I₀ · (1 − f)
行動選択:  P(b | s) = softmax( V(s, ·) / τ )
```

**二つのエンジンは別チャネルに作用する（ここが直交の構造的根拠）：**

- **報酬／SEEKING系**：正の δ で V に書き込む／ τ を広げる（探索）／ I₀ を供給する
- **恐怖系**：V には書かない。代わりに
  - (i) `τ↓`（狭窄：行動レパートリーが縮む）
  - (ii) `k↑`（近視眼化：長期・象徴報酬が割り引かれ消える）
  - (iii) 制御を **目標志向 → 習慣** へ（Arnsten：急性ストレスで前頭前野→扁桃体・線条体系）
  - (iv) 統制不能 **かつ** 慢性なら **Ĝ崩落**（無力感アトラクタ）

## 6. 形式から落ちる定理（「式が仕事をしているか」の証明）

- **定理A（報酬撤回 ＝ 罰）**：u は参照点依存で κ>1。R_eff を ρ 未満に下げると δ は負かつ κ倍に増幅され、恐怖系の動態（τ↓・回避学習）を呼ぶ。→ 報酬の撤回・相対的減額は「baseline に戻る」ではなく破壊エンジンへ押し込む別カテゴリ。**維持できない報酬は据え付けてはいけない。**

- **定理B（統制可能性の崖）**：行動は Ĝ が閾値を超える間だけ持続し、Ĝ は行動からのみ更新される（自己封止）。統制不能な結果の連続は Ĝ を閾値下の **低活動アトラクタ** へ落とし、そこは **自然回復しない**。脱出には外生的に「確実に勝てる統制可能な経験」を注入するしかない（行動活性化の知見と一致）。

- **定理C（アンダーマイニング罠）**：f が x_ext より速く立ち上がる領域で `dR_eff/dR_ext < 0`。内在価値の高い（I₀大）役割では、関与に対する顕著な金銭報酬は **実効動機を下げる**。→ 危険な役割（高I₀）と安全な報酬形態（情報的・予期せぬもの, f≈0）を式が指定する。

- **定理D（恐怖の複合コスト）**：恐怖は τ↓・k↑・習慣化を **同時に** 起こす。一軸の「動機の減少」ではなく独立3チャネルの劣化（→ 縮んだ行動集合上での局所最適ロックイン）。§1が「直交」と言った所以。

## 7. 恐怖エンジンの正当域（四重の積集合として導出）

恐怖の正当な使用域 ＝ 上の負債が **どれも噛まない条件の積集合**：

1. **抑制したい行動** であること（恐怖は回避を教え、接近を生まない。安全違反・不正・致命的ミスは可、創意・率直さ・主体性は原理的に不可）
2. **単純・習熟済み・速度依存の課題** であること（Yerkes-Dodson の複雑性交互作用：覚醒の最適点は複雑な課題ほど低い）
3. **統制可能かつ回避可能** であること（要石。無力感を生むのは罰そのものではなく統制不能な罰 / Seligman-Maier）
4. **急性であって慢性でない** こと（慢性コルチゾールは海馬＝学習基盤を損なう）

→ 知識労働の大半はこの外側にあり、そこでは恐怖は差し引きで破壊的。

### 最も鋭い反証可能予測

> **統制可能性の不連続予測**：同じ強度の罰でも、統制可能なら適応的回避、統制不能（恣意的）なら無力感。両者は連続的グラデーションではなく **質的な不連続** を示すはず。効くのは「どれだけ厳しいか」ではなく「コントロールできるか」。
