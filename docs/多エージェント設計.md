# 多エージェント層 — 設計（「文化」の形式化・A-3）

> **役割**：[正本 §8.1](正本_ミクロ機構.md) と [ロードマップ A-3](ロードマップ.md) の形式化。個々の π がどう集計され、規範・伝播・均衡になるか＝「文化」を定義し、[橋渡し](橋渡し_対応表.md)の5類型を「対応表 → 導出」へ格上げする本丸。
> **§0 堅持**：ここでも係数は機構を表すパラメータ。誇張しない。

---

## 1. アーキテクチャ

N 体のエージェント（各々 Layer1 の単一エージェント機構＝V, τ, k, Ĝ ＋マスター方程式・恐怖エンジン・帰属ゲート）を、グラフ（近傍関係）上に置く。経営者が設計できるのは依然 **C（随伴構造）と A（情動文脈）だけ**。エージェントは互いに **結合** する。

### 結合チャネル（いずれも既に Layer1 に潜在している）
1. **社会的参照点**（[§4 修正項2](正本_ミクロ機構.md)）：`ρ_i = ω·E_self + (1−ω)·(他者の結果)`。報酬の相対比較・公平性・順位。
2. **情動伝染**（[§2](正本_ミクロ機構.md) A＝共有された情動文脈）：他者の恐怖・覚醒が近傍の A を上げ、τ↓ / Ĝ↓ を誘発。
3. **観察学習**（[§1](正本_ミクロ機構.md) 自己封止の解除）：他者の (行動→結果) から Ĝ を **代理更新**。無力感が **直接経験なしに伝播** しうる。この代理更新を下方（恐怖）に使ったのが MA-1、上方（有効性・帰属ゲート付き）にも対称適用したのが [MA-8 蜂起カスケード](../sim/multiagent_uprising.py)（[応用_集団蜂起.md](応用_集団蜂起.md)）。

## 2. 「文化」「規範」の形式的定義

- **文化** ＝ 結合系の **安定な集計パターン（アトラクタ）**。母集団の状態分布 — 例：`(Ĝ, τ, 優勢行動)` の分布 — とその自己強化性で定義する。
- **規範** ＝ 母集団内で **相互に強化し合い、逸脱が割に合わない方策**（個々の最適応答が互いを支える均衡）。
- **伝播** ＝ 局所的な状態（恐怖・無力感・規範）が結合チャネル経由で母集団へ広がる過程。閾値（tipping）を持ちうる＝**文化的相転移**。

## 3. 5類型の導出計画（最終目標）

経営者の (C, A) 設計を振ると、結合系が **別々の安定 regime（アトラクタ）** に落ちる。これらが [橋渡し §3](橋渡し_対応表.md) の5類型署名（オオカミ/アリ/チンパン/ボノボ/ハイエナ）に一致するかを示す。一致すれば、5類型は「対応表（翻訳）」から「**導出（創発）**」へ格上げされる。

段階的に進める（各結合チャネルを1つずつ実装→最後に統合して (C,A) スイープ）：

## 4. MA-1：恐怖伝播（粛清カスケード）— 第1プロトタイプ

実装：[`sim/multiagent_fear_contagion.py`](../sim/multiagent_fear_contagion.py)

### 検証する主張
ロードマップ A-1 が多エージェントへ先送りした **定理D の「伝播」予測**：
> 局所的な粛清（一部エージェントへの統制不能な罰）が、直接罰を受けていないエージェントにも
> リスク回避（Ĝ↓・撤退）を **伝播** させ、母集団規模の文化的萎縮を生む。
> しかも閾値（tipping）を持つ ＝ 一定規模を超える粛清・伝染強度で **集団全体が相転移的に崩落**。

### 機構（トーラス格子 L×L、4近傍）
各ステップ（同期更新）:
- `collapsed_i = Ĝ_i < θ_giveup`。崩落（撤退）した者は **helpless 信号 s=0** を発する（§1 自己封止：撤退中は直接更新なし）。
- 健全に行動できる者：粛清窓の中のシードなら統制不能罰 `g=0`、それ以外は統制可能で成功 `g=1` → `s=g`。
- **直接更新**（非崩落のみ）：`Ĝ_i ← update(Ĝ_i, g_direct, λ_direct)`。
- **伝染更新**（全員・撤退者も観察はする）：近傍の信号平均 `s̄` へ `Ĝ_i ← update(Ĝ_i, s̄, λ_obs)`。
- `update`：上方は帰属ゲート `Ĝ←Ĝ+λ·Ĝ·(g−Ĝ)`、下方は素直に `Ĝ←Ĝ+λ·(g−Ĝ)`（[§4 修正項1](正本_ミクロ機構.md)、定理B/Dシムと同形）。

崩落は **sticky**（撤退→直接経験で回復できず、健全な隣人の観察でしか・しかも帰属ゲートで遅く回復）。
→ 局所粛清が伝染で広がり、`λ_obs`（伝染強度）が回復を上回ると母集団が相転移的に崩落する。

### 出力
- 空間カスケード（Ĝ 格子のスナップショット時系列）
- tipping（`λ_obs` スイープ → 最終崩落率の閾値曲線）
- 直接経験なしの伝播（粛清シード vs 非シードの平均 Ĝ、伝染 ON/OFF 比較）

詳細・観測値は [sim/README.md](../sim/README.md) の MA-1 節。
