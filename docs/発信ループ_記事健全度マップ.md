## 決着：crowding-out.md（§0判断で意図的例外に登録）

- **検出内容**：式記号あり／動物の具体比喩語ゼロ。
- **精読結果**：託児所の罰金・献血の謝礼＝**人間の制度・経済の事例が主役**。動物の具体描写（サル/犬/ラット等）は無く、「動物実験で確立した機構が檻の外へ届いた」という**参照**にとどまる。
- **ただし**：この記事は「**ドメイン外の一致**（蜂起・取り付けに続く第三）」がテーマ＝**あえて人間制度を主役にし、動物機構の描写は [reward-trap](../site/src/content/articles/reward-trap.md) に委譲する構成**。薄さは意図的な可能性が高い。
- **判断（§0・人間・2026-06-15 確定）**：**(a) 設計意図として現状維持**を採用。記事は触らず、採点器の `EXEMPT_THIN_METAPHOR`（`scripts/verify-article.py`）に理由付きで登録 → 比喩チェックのみ免除し WARN0（誇張・frontmatter 等の他チェックは継続）。免除理由は採点器の INFO に毎回表示＝隠さない。将来この記事に動物実験の具体を足したくなれば例外を外せばよい。

## 検出器の既知の限界（更新・§0）

1. **語彙ベースで意味は読めない**：比喩が「式に薄まっていないか」「誇張か」の最終判断は人間。スクリプトは入口のトリアージ。
2. **METAPHOR は手動メンテ**：新しい動物・実験を扱う記事を書いたら、固有名（動物種・研究者実験）が語彙に無いと誤って比喩ゼロ判定しうる → 必要に応じ `scripts/verify-article.py` の METAPHOR に追記。
3. 固定タグ `#動物行動学` はこのスクリプトでは見ない（note入稿時付与・既存遡及は人間別タスク）。
