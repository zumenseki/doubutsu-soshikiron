# 操作化⑤ — 実施プロトコル雛形（設計 → 実施の橋）

> **役割**：操作化②③④ は予測を**反証可能な設計**まで降ろした。本 doc はその次の一段——**設計を実際に走らせる足場**（検出力・サンプル設計・事前登録テンプレ）——を、代表2予測（[予測1 統制可能性の不連続](操作化_予測プロトコル.md)・[予測3 危険役割ほど金銭逆効果](操作化_予測プロトコル.md)）で示す雛形。実データに当てるのは現実世界の作業（理論側の責務はここまで）。
>
> **§0 堅持（このタスクの肝）**：
> 1. **効果量は「計画用の仮定」であって理論の予測ではない**。本理論が予測するのは **構造**——符号の反転・不連続・交互作用——であって、効果の**大きさ**ではない（[正本 §0](正本_ミクロ機構.md)：係数は機構を表すパラメータで観測値でない）。だから検定の**標的は構造**で、効果量は「どれくらいの N があればその構造を検出できるか」の**感度分析**に使うだけ。
> 2. **事前登録こそが価値**：本 doc の目的は「精密に当てる」ことでなく、**p-hack を封じて反証可能性を担保する**こと（§0 価値②と整合）。
> 3. **走らせていない**：これは雛形。実施・実データ収集・結果は範囲外。必要 N が現実的規模で賄えないなら、誠実な結論は「現スケールでは検定不能」であって「基準を下げる」ではない。

---

## 1. なぜ「実施雛形」が要るか

設計（操作化②③④）は「何を観測したら誤りか」を与えた。だが実際に走らせるには、さらに **(a) どれだけのサンプルで構造を検出できるか（検出力）、(b) 誰を・どう割り付けるか（サンプル設計）、(c) 解析前に何を約束するか（事前登録）** が要る。これが無いと、(a) 検出力不足で「差なし」を誤って反証と読む／(b) 交絡で偽陽性／(c) 事後の都合解釈（HARKing・optional stopping）で「やっぱり支持」に流れる。

**重要な非対称**：理論は**構造**を予測し**大きさ**を予測しない。よって——
- 検出力計算の効果量は **仮定**（小/中/大の感度で幅を出す）。
- 検定する帰無仮説 H0 は「**構造が無い**」（連続／加法的／交互作用なし）、対立 H1 は「**構造がある**」（不連続／符号反転／交互作用あり）。
- 「効果量がこの値」という主張は本理論からは出ない——出すと §0 違反。

## 2. 実施6項フォーマット（共通）

| 項 | 中身 | §0 上の注意 |
|---|---|---|
| **① 仮説（構造）** | H0＝構造なし／H1＝構造あり（符号反転・不連続・交互作用） | 大きさでなく**構造**を検定 |
| **② 主要アウトカム＆単位** | 事前指定の主要指標1つ・分析単位（個人/チーム/組織）・**行動痕跡**（自己申告でなく） | 主要1つに絞る（多重性回避） |
| **③ 群・割付** | A/B（割付単位・無作為化）or 自然実験（DiD・マッチ共変量） | 割付の外生性 |
| **④ 検出力雛形** | 効果量＝**計画用仮定**（小/中/大の感度）→ α・power → 必要 N。クラスタ設計は design effect で割増 | 効果量は予測でなく仮定・感度表で幅 |
| **⑤ 事前登録テンプレ** | 主要解析モデル・**停止規則**（覗き見禁止）・**反証域**（②③④の反証条件を再掲）・多重比較・除外基準 | これが反証可能性の担保 |
| **⑥ 実施の落とし穴** | 予測固有の交絡＋一般（観測者効果・脱落・群間汚染） | 測れていない物を明示 |

> **検出力の一般則（雛形で繰り返し効く）**：(a) **交互作用・不連続の検定は主効果より N が要る**（同じ効果量でも交互作用は概ね4倍規模）。本理論の予測は多くが交互作用/不連続ゆえ N は大きめに見積もる。(b) **割付がチーム/組織単位なら個人 N でなく**クラスタ数が効く（級内相関 ICC で design effect 1+(m−1)ρ 倍）。(c) 効果量が不明だからこそ**小/中/大の3点で必要 N を出し**、「中でも非現実的な N」なら設計を見直す。

## 3. 実施例A — 予測1「統制可能性の不連続」（定理B・[操作化②§3](操作化_予測プロトコル.md)）

**①仮説（構造）**
- **H1（構造あり）**：罰の**強度を一定**にしたとき、統制可能群と統制不能群で適応的反応（改善着手）に**不連続な段差**が出る／統制不能群で「やっても無駄」が**般化**する。
- **H0（構造なし）**：反応は強度の**連続関数**で、統制可能性の境界で段差が出ない・般化も無い。
- → 検定の標的＝**統制可能性 × アウトカムの不連続/交互作用**（強度を共変量で統制）。大きさは問わない。

**②主要アウトカム＆単位**：主要＝**改善着手率**（叱責後 N 日内に当該領域で新しい対処を試みた割合・**行動ログ**で計数）。副次＝撤退ラッチ・般化（無関係領域への波及）。単位＝チーム（割付単位）。

**③群・割付**
- *A/B*：是正フィードバックを **改善路つき（可制御）** vs **評価のみ（不能）** でチーム無作為割付。**強度・伝達者・対象ミスをマッチ**。
- *自然実験（代替）*：基準非公開の相対評価 → 基準公開（可制御化）へ制度変更した部署の **DiD**（統制部署比較）。

**④検出力雛形**（数値は計画用の仮定・親方が実値で埋める）
- 主要効果量＝可制御群と不能群の**着手率差**（比率差 p_c − p_u）。
- 感度表の骨格：

| 効果量(仮定) | 例 | 検定 | 必要 N の方向 |
|---|---|---|---|
| 小 | 比率差 ~0.1 | 2群比率検定（強度共変量込み） | 大（数百/群〜） |
| 中 | ~0.2 | 同上 | 中 |
| 大 | ~0.3+ | 同上 | 小 |

- α=0.05・power=0.8 を既定。**チーム単位割付**ゆえ個人 N を ICC の design effect（1+(m−1)ρ）で割増し、**有効単位＝チーム数**で再計算。不連続/般化（交互作用寄り）は主効果より N 増。**「中」でも非現実的なチーム数なら検定不能と判断**（基準は下げない）。

**⑤事前登録テンプレ**
- 主要仮説＝強度をマッチした上で（着手率 可制御 − 不能）>0、かつ強度連続成分を超える**境界段差**。
- 主要解析＝混合モデル（チーム random effect・強度 fixed covariate）／不連続は強度×統制性の交互作用項。
- **反証域**（操作化②§3 再掲）：着手率が**強度の連続関数のみ**で説明され境界段差が出ない／不能群で着手率が下がらない・般化なし → **反証**。
- 停止規則＝**固定 N・中間覗き見なし**（逐次なら α 消費を事前計画）。除外＝割付前に定義（途中異動・データ欠損）。多重比較＝主要1つ・副次は補助で別扱い。

**⑥実施の落とし穴**
- 可制御フィードバックは口調も穏やかになりやすい（**強度と交絡**）→ 強度コーディングでマッチ。
- 選択効果（無力な個体ほど恣意的に扱われる）→ 自然実験で緩和。
- 群間汚染（隣チームが手本を見る）・差動脱落。アウトカムは**行動ログ**で（観測者効果回避・[操作化②⑥](操作化_予測プロトコル.md)）。

## 4. 実施例B — 予測3「危険役割ほど金銭は逆効果」（定理C・[操作化②§5](操作化_予測プロトコル.md)）

**①仮説（構造）**
- **H1（構造あり）**：内在価値の高い（I₀大）役割では、統制的金銭報酬が無報酬文脈の自発的関与を**下げる（符号反転）**／**I₀ × 報酬形態の交互作用**が有意（高I₀×統制的 が 低I₀ や 情報的 より悪い）／撤去後も内発が戻らない（**置換の残存**）。
- **H0（構造なし）**：金銭報酬は I₀ に依らず**加法的/正**（交互作用なし・符号反転なし・撤去で即回復）。
- → 標的＝**I₀ × 報酬形態の交互作用の符号**（＋撤去後の残存）。大きさは問わない。

**②主要アウトカム＆単位**：主要＝**無報酬文脈の自発的関与**（無報酬時間の継続・手抜き可能場面の丁寧さ・**行動**）の **導入前後変化**。単位＝個人 or 役割グループ（割付単位に合わせる）。

**③群・割付**
- *A/B（2×2）*：I₀（高/低）× 報酬形態（統制的・有形・予期 / 情報的・予期せぬ）。**金額を一定にして形態だけ操作**（額の交絡を切る）。導入前ベースライン取得 → 前後差（DiD）。
- *撤去フェーズ*：インセンティブ撤去後の自発関与を追跡（置換の残存＝戻らないか）。
- *倫理*：高I₀役割で内発を故意に壊す介入は不可 → **自然発生する制度ロールアウトの観察**が現実解（[操作化②⑥](操作化_予測プロトコル.md)）。

**④検出力雛形**（数値は計画用の仮定）
- 主要効果量＝**交互作用項**（I₀×形態）の大きさ。**交互作用は主効果より N が要る**（同効果量で概ね4倍規模）＝本例の N は大きめ。
- 感度表の骨格：効果量 小/中/大（例 Cohen f² や セル平均差）→ α=0.05・power=0.8 → 必要 N（交互作用ゆえ主効果の~4倍を起点）。
- 撤去フェーズ＝対応のある前後（paired）で別途検出力。**「中」でも非現実的 N なら検定不能と明記**（基準は下げない）。クラスタ割付なら design effect で割増。

**⑤事前登録テンプレ**
- 主要仮説＝I₀×形態 交互作用が**負**（高I₀×統制的セルが無報酬 baseline を下回る）＋撤去後に money 群が control を下回る（残存）。
- 主要解析＝2要因 ANOVA/回帰の**交互作用項**（前後差を従属）／撤去フェーズは paired。
- **反証域**（操作化②§5 再掲）：高I₀群でも金銭で下がらない（or 上がる）／撤去後**速やかに回復**／**交互作用なし**（高低同方向） → **反証**。
- 停止規則＝固定 N・覗き見なし。除外＝事前定義。多重比較＝主要は交互作用1つ。

**⑥実施の落とし穴**
- 額×形態の交絡 → **額マッチ**必須（少額の「侮辱」効果＝別経路 Gneezy-Rustichini を分離）。
- I₀ 測定の自己申告バイアス → **行動代理**（無報酬時間の関与）を主に（[操作化②⑥](操作化_予測プロトコル.md)）。
- 外的妥当性（特定文脈）・自然ロールアウトは「なぜ導入したか」と交絡。撤去フェーズの脱落。

## 5. §0 — この雛形の限界

1. **効果量は仮定・構造が予測**：本理論は符号反転・不連続・交互作用という**構造**を予測する。検出力の効果量は「その構造を検出するのに必要な N」を見積もる**計画用の仮定**であって、理論が「効果はこの大きさ」と言っているのではない（[正本 §0](正本_ミクロ機構.md)）。感度表で幅を出すのはそのため。
2. **事前登録が目的**：精密な点推定でなく、**反証可能性の担保**（p-hack・HARKing・optional stopping の封じ込め）が本 doc の価値（§0 価値②）。
3. **検出力計算自体が仮定に乗る**：分布・等分散・クラスタの ICC 等。**チーム/組織単位の割付は design effect で必要数が膨らむ**（個人 N の素朴計算は過小）。
4. **走らせていない・実値は親方ドメイン**：これは雛形。実施・収集・結果は範囲外。**「中」効果量でも必要 N が現実スケールを超えるなら、誠実な結論は『現スケールでは検定不能』**（基準を下げて無理に有意を出さない）。
5. **代表2例のみ**：他18予測（ドメイン外③・集団regime④）は同型に展開できるが、史料・cross-org は検出力でなく**同定（割付の外生性）**が律速＝雛形の重心が違う（[操作化③§2](操作化③_ドメイン外検証.md)・[操作化④§2](操作化④_集団regime検証.md)）。
