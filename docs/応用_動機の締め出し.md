# 応用 — 報酬による動機の締め出し（アンダーマイニング）のドメイン外適用（内発の置換 ↔ 定理C）

> **この doc の役割**：Layer1 機構を「報酬設計の現場（献血・保育・OSS・ボランティア）」に当て、機構の **到達域(reach)** を確かめる。蜂起（[応用_集団蜂起.md](応用_集団蜂起.md)）・取り付け（[応用_取り付け騒ぎ.md](応用_取り付け騒ぎ.md)）が **多エージェント伝播** の一致だったのに対し、本 doc は **単一エージェントの動機の置換**（定理C）＝質的に新しい側面の第6の一致。
> **§0 厳守**：証明ではなく到達域の実証。consilience（独立証拠系統の収束）。ただし ④⑤ より独立性は弱い（後述）。係数は測っていない。

---

## 0. この doc の身分（第6の一致・consilience）

- **実験系（個体・ミクロ）**：内発的動機づけの実験心理学（Deci 1971・Deci-Koestner-Ryan 1999 メタ分析＝有形・予期・統制的報酬が内発を下げる）＋ 動物の SEEKING 系（Panksepp／Berridge＝活動それ自体が報酬）。正本では内在価値 I₀ と抑制関数 f。
- **現場・社会系（マクロ・field）**：社会政策（Titmuss 1970 献血＝金銭化が供血意欲を損なう ※論争あり）・経済学のフィールド実験/理論（Gneezy-Rustichini 2000「A Fine is a Price」託児所の遅刻罰金 → 遅刻 *増*／Frey の motivation crowding／Bénabou-Tirole 2003）。

両系統が「**外発報酬が内発を駆逐する**」で出会うなら、機構は檻の外——人間の制度設計——にも届いている。

ただし **独立性は ④⑤ より弱い**（§0 誠実）。motivation crowding の経済学（Gneezy-Rustichini・Frey・Bénabou-Tirole）は Deci の心理学を **明示的に参照して** 築かれた＝「互いに参照せず独立収束」とは言えない。誠実に数えると、独立に立つのは〈内発の実験心理／動物 SEEKING 系〉と〈現場が機構を知らずに観測した事実（Titmuss の献血供給・託児所のフィールド実験で罰金が遅刻を増やした観測）〉の **2系統**。経済理論は前者に依存するので「独立な第3系統」には数えない。

---

## 1. 問い — なぜ報酬を足すと、かえってやらなくなるのか

通俗経営論は動機を1本のダイヤルと見る（報酬↑→動機↑）。だが現場では逆が起きる：献血に謝礼を付けると供血が減り、託児所に遅刻罰金を入れると遅刻が増える。**報酬を足したのに行動が減る。** 動機を1ダイヤルと見るモデルからは出ない。二層理論は、これを「報酬が内発を *置換* する」という単一エージェントの式から導く。

---

## 2. 機構 ＝ 定理C（内発の置換）

正本の修正項3＋定理C（[正本 §4・§6](正本_ミクロ機構.md)）：

```
R_eff = D(t) · (w · x_ext) + I₀ · (1 − f)
```

- **I₀** ＝ 行動それ自体の内在価値（SEEKING 系が「活動＝報酬」にする分）。
- **f** ＝ 内在価値の抑制関数。報酬が **有形・予期され・統制的** だと f大、**情報的・予期せず・有能感を伝える** と f≈0（Deci-Koestner-Ryan）。

顕著な外発 x_ext を足すと、第1項は増えるが、f が立ち上がって第2項 I₀·(1−f) が削れる。**f が x_ext より速く立つ領域で dR_eff/dx_ext < 0** ＝ 報酬を足すほど実効動機が下がる（定理C）。

→ 罠は **内在価値が高い役割（I₀ 大）× 統制的報酬** でだけ起きる。式が危険域を名指しする。

---

## 3. 式から落ちる定量（[sim/theorem_c_undermining.py](../sim/theorem_c_undermining.py)・決定論）

sim は乱数なしの解析（導関数の符号についての主張なので R_eff の解析が忠実な検証）。抑制を f = f_max·x_ext/(x_ext+x_half)（飽和・小 x で急峻）でモデル化し、3ケースを isolate：

| ケース | 結果 |
|---|---|
| **高I₀ × 統制的** | **罠**：dR_eff/dx_ext < 0。R_eff が *無報酬の baseline I₀ を下回る*＝**報酬を払う方が、払わないより悪い** |
| 低I₀ × 統制的 | 罠なし（削る内発が小さい） |
| 高I₀ × 情報的(f≈0) | 罠なし（内発を削らない） |

- **undermining 閾値**：`I₀ > D·w·x_half / f_max` を超える役割では x_ext→0 から（最初の1円から）報酬が逆効果。
- **罠の深さ**：無報酬 baseline と最小 R_eff の差。一度沈むと baseline へ戻すのに大きな x_ext を要する（＝撤回しても元に戻りにくい・§6-3）。

（sim は結論をハードコードせず機構の式から符号を導く。要素［I₀・報酬の性格］を isolate して罠の発生条件を公平に切り分ける。）

## 4. 蜂起・取り付けとの対比 ＝ 伝播でなく「置換」という新側面（★第6の一致の核）

④⑤と並べると、第6が *なぜ新しいか* が見える：

| | 蜂起④(MA-8) | 取り付け⑤(MA-1) | 動機の締め出し⑥(定理C) |
|---|---|---|---|
| 機構の層 | 多エージェント **伝播** | 多エージェント **伝播** | 単一エージェントの **置換** |
| 伝播するもの | 有効性 Ĝ↑（勇気） | 恐怖駆動の回避 | （伝播しない） |
| 核の現象 | 集計で相転移 | 集計で相転移 | I₀ が x_ext に *潰される*（f） |
| 通俗論との分岐 | 「群衆心理」では非対称が出ない | 同上 | 「報酬↑→動機↑」の1ダイヤル観が破れる |

→ ④⑤は「個の機構を多数で集計すると新現象」。⑥は集計を経ず、**単一エージェントの式の中で外発が内発を駆逐する**。レビュー教訓「一致を水増しせず、新機構の *別側面* を示せ」に対応した、質的に異なる到達域。

## 5. 動機の締め出し × 機構 対応表

| 局面 | 機構 | 動機の締め出し |
|---|---|---|
| **素地** | I₀ 大（活動＝報酬の役割） | 献血・OSS・ケア・自発的な専門職 |
| **引き金** | 統制的・有形・予期される x_ext | 謝礼・出来高・遅刻罰金・監視付き報奨 |
| **抑制** | f↑ → I₀·(1−f) 減 | 「やりたいから」→「いくらで／言われたから」へ意味が変質 |
| **逆効果** | dR_eff/dx_ext < 0 | 供血減・遅刻増・貢献減 |
| **安全形態** | f≈0（情報的・予期せぬ・有能感） | 事後の承認・予期せぬ謝意・裁量と熟達の付与 |

## 6. ここから落ちる検証可能予測

1. **高I₀ ほど金銭は逆効果**：内在価値の高い役割（ケア・研究・OSS・献血）ほど、統制的報酬の導入で行動が *減る*。低I₀ の単純作業では素直に増える。←定理C 閾値
2. **報酬の *性格* が符号を決める**：同額でも情報的・予期せぬ承認（f≈0）は安全、統制的・予期される金銭（f大）は危険。額でなく形態。
3. **撤回も危険**：一度据えた報酬を下げる／外すと、定理A（参照点 ρ・κ>1）で *損失* として効き、回復しない（baseline へ戻すのに大きな x_ext を要する＝sim の「罠の深さ」）。→「やめれば元通り」ではない。
4. **罰金は価格になる**：禁止のための罰金が「対価」と読み替えられ、抑止したい行動を *増やす*（Gneezy-Rustichini）。＝統制的シグナルが規範を金銭関係に置換。

## 7. §0 の誠実さ（この doc がやっていないこと）

- **独立性の限界（最重要）**：motivation crowding の経済学（Gneezy-Rustichini・Frey・Bénabou-Tirole）は Deci の心理学を参照して成立＝ ④⑤のような「互いに無参照の独立収束」ではない。独立に立つのは〈内発の実験／動物 SEEKING 系〉と〈現場の観測事実（献血供給・託児所フィールド実験）〉の2系統。経済理論は独立系統に数えない（水増ししない）。
- **Titmuss 論争**：献血の金銭化が供給を下げるという Titmuss 1970 の主張には反証・再分析の論争がある（文脈依存）。単一の決定的証拠としては扱わない。
- **特定文脈の実験**：Gneezy-Rustichini はイスラエルの託児所の自然実験＝外的妥当性に限界。一般法則として断定しない。
- **到達域 ≠ 証明**：consilience は機構がヒトの制度に届くことの傍証。収束＝真ではない（共通のヒト／動物の動機心理が両者を別々に生むだけ、という解釈も残る。ただしその場合でも「機構がヒトに届く」当の主張は支持される）。
- 係数は測っていない。f・I₀ の値は機構表現のパラメータで観測値ではない。
