# 操作化③ — ドメイン外予測の反証化（蜂起・取り付け・動機の締め出し）

> **役割**：[操作化_予測プロトコル.md](操作化_予測プロトコル.md)（操作化②）が橋渡し §7 の**組織内4予測**を A/B・組織内自然実験へ降ろしたのに続き、本 doc は**ドメイン外の応用予測**——集団蜂起（歴史）・取り付け騒ぎ（金融）・動機の締め出し（政策/フィールド）が各 §6 で出した固有予測——を反証可能な形へ降ろす。組織内の核4予測（統制可能性の不連続／撤回>据付／金銭逆効果）は[操作化② §3–6](操作化_予測プロトコル.md)で済んでおり、ここでは**再録せずリンクし、各応用 doc に固有の予測のみ**を扱う（避重複）。
>
> **§0 堅持（最優先）**：本 doc も**測定の設計**であって結果ではない。ドメイン外は**介入できない**（歴史は実験できない・銀行を故意に取り付けさせられない）ので、依拠するのは**既存記録の自然実験・event study・クロスセクション**。それゆえ §0 の誠実さは組織内より重い——**史料の生存バイアス・逆因果（事後の語りの機構的再構成）・交絡（政治機会構造／ファンダメンタルズ／文脈依存）**を各予測で明示する（各応用 doc §7 と整合）。consilience は到達域の**傍証**であって証明ではない（[橋渡し §0/§1](橋渡し_対応表.md)・[正本 §0](正本_ミクロ機構.md)）。

---

## 1. なぜドメイン外の操作化は組織内と違うか

組織内（操作化②）は**介入できる**——フィードバック枠組みを A/B し、インセンティブ制度のロールアウト前後を測れる。ドメイン外はできない。代わりに3つの強みがある（[応用_集団蜂起 §1](応用_集団蜂起.md)）：

- **out-of-sample**：機構を当てに行ったのでなく、後から当たる。記録は機構を知らずに残された。
- **記録が厚い**：年貢率・米価・賃金・預金流出・動員規模の**時系列**が残り、参照点割れや tipping を追える。
- **大規模**：個体差が平均化され機構の signature が出やすい。

→ 操作化の単位は「介入の割付」でなく「**自然実験の同定**」：機構が予測する分岐が、記録の中で**通俗説の予測と逆符号・不連続**になる箇所を探す。

## 2. 共通フォーマット（ドメイン外版・6項）

操作化② §2 の6項を、介入不能なドメインへ翻案する。**④が「実験デザイン」から「同定戦略（どの自然実験・event study・断面で分岐を見るか）」に変わる**のが核。

| 項 | 中身 | ドメイン外での注意 |
|---|---|---|
| **① 機構的主張** | どの定理/MA から落ちるか | 応用 doc の対応節を指す |
| **② 操作的定義** | 独立・従属変数を**記録可能な量**で | 「相対的剥奪」「可視性」を時系列・断面の観測量に |
| **③ データ源・指標** | どの史料・統計・event か | 年貢/米価/賃金・預金流出速度・献血供給 等 |
| **④ 同定戦略** | 自然実験／event study／断面比較 | 割付の外生性が命（個体特性で割り付かない事象を選ぶ） |
| **⑤ 反証条件** | **何が出たら予測は誤りか** | 通俗説（絶対窮乏・群衆心理）が当て、機構の分岐が出ない |
| **⑥ 交絡と限界** | 対抗仮説・記録バイアス | 政治機会構造・ファンダ・生存バイアス・逆因果 |

> **横断の交絡（ドメイン外固有）**：(a) **逆因果**＝機構が現象を生むのか、事後の語りが機構的に再構成されるのか（史料の生存バイアス）。(b) **第三要因**＝蜂起なら政治機会構造・資源動員・国家能力（Tilly）、取り付けなら実際の債務超過、締め出しなら文脈依存。機構は「複数要因の一つ」で、本 doc はそれらを**排除しない**（[応用_集団蜂起 §7](応用_集団蜂起.md)）。

## 3. 集団蜂起（歴史）— [応用_集団蜂起 §6](応用_集団蜂起.md)

> 核4のうち「統制可能性の不連続」は[操作化② §3](操作化_予測プロトコル.md)で操作化済（弾圧の恣意性×鎮静/爆発）。ここでは蜂起**固有**の4予測。

### B1. 反転仮説（J字）— 定理A
- **②操作的定義**：従属＝蜂起の発生・件数（年・地域）。独立＝厚生代理（実質賃金・米価の逆数・実質年貢残）の**時系列の形状**——「単調悪化」か「改善後の急反転（J字）」か。
- **③データ源**：百姓一揆件数の年次統計／米価・年貢率史料／革命前の経済指標（Davies の J-curve データ）。
- **④同定戦略**：厚生時系列の**変曲（改善→反転）**の有無で地域・期間を層別し、蜂起発生率を比較（断面×時系列）。
- **⑤反証条件**：蜂起が**厚生のピーク（最悪期）に集中**し、改善→反転の局面と相関しない → J字＝**反証**＝「貧しいほど反乱」説が支持。
- **⑥交絡**：凶作・人口圧は厚生悪化と蜂起を同時に動かす（共通原因）→ 反転の「形状」を見ることで水準効果と分離。生存バイアス（記録された一揆は大規模に偏る）。

### B2. 参照点割れ ＞ 絶対窮乏 — 定理A・参照点の社会性（ρ=ω·E_自己+(1−ω)·他者）
- **②操作的定義**：独立を2つ——**絶対窮乏度**（生活水準の絶対値）と**相対的剥奪度**（直近の据わり ρ からの低下幅／近隣・他層との差）。どちらが蜂起をよく予測するか。参加者の出身**階層**（最貧層か「下がった層」か）。
- **③データ源**：賃金・保有の分布データ／参加者の社会的属性の史料。
- **④同定戦略**：両指標を同一回帰に入れ、相対的剥奪が絶対窮乏を超えて説明力を持つか（断面パネル）。参加者階層の分布を予測（最貧でなく中位の「下落層」）。
- **⑤反証条件**：絶対窮乏度が相対的剥奪度を圧倒し、**最貧層が最も参加** → 参照点割れ仮説は**反証**。
- **⑥交絡**：相対的剥奪と絶対窮乏は相関しやすい（分離には分布の裾と「下がった中位層」の同定が要る）。記録に残る属性の偏り。

### B3. 閾値・突発性 — MA-1 / [MA-8](応用_集団蜂起.md)
- **②操作的定義**：従属＝同程度の不満量が**暴動になるか沈黙か**の分岐。独立＝**早期決起者（オルグ・義民・傘連判）の有無**と参加の**時間的形状**（漸増か閾値的急増か）。
- **③データ源**：動員規模の時系列（参加者数の立ち上がり）／首謀構造の史料（傘連判状＝初期コスト分散装置）。
- **④同定戦略**：参加曲線が**S字/急峻な相転移**か連続増加かを判定（時系列）。同一不満量で早期決起者の有無により帰結が分岐する事例対を比較（Kuran 選好カスケード・Granovetter 閾値の経験的痕跡）。
- **⑤反証条件**：参加が不満量の**連続関数として滑らかに増える**（閾値・突発が無い）、早期決起者の有無が帰結を分けない → 相転移仮説は**反証**。
- **⑥交絡**：弾圧による過小報告が立ち上がりを歪める／予測困難性そのものが機構の予測ゆえ、事後の「必然だった」語り（後知恵）に注意。

### B4. 脱出の外生性 — 定理B
- **②操作的定義**：従属＝長い忍従からの**決起**。独立＝**外生の「勝てる」シグナル**（指導者の出現・近隣他地域の成功・権威の亀裂＝凶作で領主正統性低下/取締弛緩/戦争での国家能力低下）の有無。
- **③データ源**：近隣一揆の波及・連鎖の時空間パターン／権威の弱化イベント（飢饉・戦争・政変）の年表。
- **④同定戦略**：決起が**内的不満の蓄積だけ**から自然発生するか、**外生シグナルの直後**に集中するか（event study：シグナル前後の決起率）。鎮圧後の指導者処刑→再封止（決起率の事後低下）も観測対象。
- **⑤反証条件**：外生シグナルが**無くても**忍従が内側から決起へ転じる（蓄積だけで発火）→ 「自然回復しない／外生注入が要る」定理B は**反証**。
- **⑥交絡**：外生シグナル（凶作）は厚生悪化（定理A の火種）と同時に来る→ B1/B2 と切り分けるには「窮乏は同等だがシグナル有無が違う」事例対が要る。

## 4. 取り付け騒ぎ（金融）— [応用_取り付け騒ぎ §6](応用_取り付け騒ぎ.md)

> 恐怖伝播 MA-1 の金融版。介入不能だが**event study に最も向く**（取り付けは時刻分解能の高い記録が残る）。

### B5. 可視性が閾値を下げる（λ増大）— MA-1
- **②操作的定義**：従属＝**取り付けの速度**（疑念発生→預金流出が臨界に達するまでの時間／単位時間あたり流出率）。独立＝**他者の引き出しの可視性**（窓口の物理的行列／SNS・ニュースの拡散強度＝結合 λ の代理）。
- **③データ源**：預金流出の時系列（時間/日単位）／報道・SNS 指標／時代区分（pre-SNS vs SNS）。事例＝大恐慌期（1930–33・日単位）vs Northern Rock 2007 / SVB 2023（時間単位）。
- **④同定戦略**：可視性の異なる事例間で速度を比較（自然実験的・event study）。同一時代内で SNS 露出の高低と速度の相関。
- **⑤反証条件**：可視性（行列・SNS 露出）と取り付け**速度が無相関**、デジタル期と前デジタル期で速度が**変わらない** → λ 増大仮説は**反証**。
- **⑥交絡**：SNS 時代は送金技術も速い（引き出し自体の物理速度↑）→ 「可視性による伝播」と「決済技術による実行速度」を分離する必要。報道は破綻と同時内生（逆因果）。

### B6. ファンダメンタルズ非依存成分 — Diamond-Dybvig / Morris-Shin
- **②操作的定義**：従属＝取り付けの発生。独立＝**事後監査の健全性**（ex-post で支払可能だったか）。健全でも起きた取り付け＝協調失敗成分。
- **③データ源**：破綻行の事後清算・資産査定／同程度ファンダで帰結が分かれた銀行対。
- **④同定戦略**：ファンダメンタルズ（自己資本・資産質）をマッチした銀行対で取り付け有無を比較（断面）。健全側でも起きるなら協調成分の存在。
- **⑤反証条件**：取り付けが**すべて事後の債務超過で説明**でき、健全行では起きない → 「ファンダ非依存の協調成分」は**反証**（純粋なファンダメンタルズ説が支持）。
- **⑥交絡**：ファンダの事前情報は不完全（噂が当たっていた可能性＝Morris-Shin のグローバルゲームは情報構造で均衡が決まる）→ 「健全」の判定時点（事前情報集合）に注意。

### B7. 保険は tipping を消す — MA-1 伝染 OFF
- **②操作的定義**：従属＝取り付け確率。独立＝**預金保険の有無/カバー範囲**（被保険 vs 非保険預金）。保証＝「引き出さなくても安全」の外生注入。
- **③データ源**：FDIC 導入（1934）前後の取り付け頻度／被保険・非保険預金の引き出し挙動（SVB は非保険比率が高く高速流出）。
- **④同定戦略**：**保険導入を自然実験**（前後の取り付け頻度の差）。カバー上限を**回帰不連続**（上限直下=保護/直上=非保護の引き出し率の段差）。
- **⑤反証条件**：保険導入で取り付け頻度が**下がらない**、被保険預金が非保険と**同じ速さで流出** → 「外生保証が伝染を遮断」は**反証**。
- **⑥交絡**：保険導入は規制強化・監督厳格化と同時（パッケージ）→ 保険単独の効果分離が難しい。被保険/非保険は預金者属性（大口/小口）と相関。

### B8. 蜂起との非対称（恐怖伝播 < 有効性伝播）— [figK3](応用_取り付け騒ぎ.md)
- **②操作的定義**：同一社会・同一時代で、**取り付け（恐怖伝播）の起きやすさ/速さ** と **蜂起（有効性伝播）の起きやすさ/速さ** を比較。機構予測＝取り付けは低結合・短時間で頻発、蜂起は高結合・稀。
- **③データ源**：同時代の金融パニック頻度 vs 民衆蜂起頻度／各々の立ち上がり時間。
- **④同定戦略**：クロスドメイン比較（同一社会内で2現象の発生率・速度を対比）。帰属ゲートの有無（取り付け=不要/蜂起=要）が頻度差を生むという機構予測の符号検証。
- **⑤反証条件**：蜂起が取り付けと**同程度に頻発・高速**、または取り付けの方が稀 → figK3 の非対称（恐怖はゲートなしで容易・勇気は帰属ゲートで稀）は**反証**。
- **⑥交絡**：制度的抑圧の強さが蜂起頻度を直接下げる（機構と独立）→ 「制度的弾圧が同等」な比較が要る。2現象の「発生」定義の非対称（何をもって1件か）。

## 5. 動機の締め出し（政策・フィールド）— [応用_動機の締め出し §6](応用_動機の締め出し.md)

> 「高I₀ほど金銭逆効果（§6-1）」「撤回も危険（§6-3）」は核4＝[操作化② §5・§4](操作化_予測プロトコル.md)で操作化済。ここでは**フィールド/政策固有**の2予測。組織内 A/B より**自然発生する制度導入の観察**が現実的（[応用 §7 外的妥当性](応用_動機の締め出し.md)）。

### B9. 報酬の「形態」が符号を決める（額でなく形態）— 定理C・f
- **②操作的定義**：独立＝報酬の**形態**（統制的・有形・予期＝f大 ／ 情報的・予期せぬ・有能感＝f≈0）を、**金額を一定にして**操作。従属＝無報酬文脈での自発的関与。
- **③データ源**：献血・OSS・ケア・専門職での報奨制度の**形態差**（出来高 vs 事後承認）の field データ／フィールド実験。
- **④同定戦略**：**金額マッチ×形態の自然比較**（同額でも統制的 vs 情報的を導入した組織/制度の対比）。理想は形態をランダム化する field RCT。
- **⑤反証条件**：同額なら形態（統制的/情報的）で**符号が変わらない**（額だけが効く） → 「形態が符号を決める」は**反証**。
- **⑥交絡**：形態と金額・文脈は実務で相関（出来高は高額になりがち）→ 額マッチが要。形態の操作的コーディング（何が「統制的」か）の妥当性。

### B10. 罰金は価格になる — Gneezy-Rustichini
- **②操作的定義**：従属＝抑止したい行動の頻度（遅刻・違反）。独立＝**罰金（統制的シグナル）の導入**。機構予測＝高規範文脈で罰金が「対価」と読み替えられ行動が**増える**（規範→金銭関係への置換）。
- **③データ源**：託児所遅刻罰金（Gneezy-Rustichini 2000・遅刻増→撤回後も戻らず）／類似の罰金導入の自然実験（図書館延滞・環境課金 等）。
- **④同定戦略**：**罰金導入の前後＋撤回後**（差分の差分・撤回後の非回復＝置換の残存）。文脈（事前の規範の強さ）でモデレート。
- **⑤反証条件**：罰金導入で対象行動が**常に減る**（増える文脈が無い）、撤回後に**速やかに元へ戻る** → 「罰金=価格・規範置換」は**反証**。
- **⑥交絡**：罰金額が低すぎて抑止力が単に弱いだけ（「価格化」でなく「弱い罰」）→ 額と「意味の変質」を分離。外的妥当性（イスラエル託児所の特定文脈・[応用 §7](応用_動機の締め出し.md)）。

## 6. §0 — このドメイン外プロトコルの限界

操作化② §8 の限界に**ドメイン外固有の上乗せ**：

1. **介入できない＝自然実験頼み**：割付の外生性が常に争点。歴史・金融・政策は「条件を揃えた実験」ができず、**第三要因（政治機会構造・ファンダメンタルズ・文脈）を排除しきれない**（各応用 doc §7）。機構は「複数要因の一つ」。
2. **史料の生存・逆因果バイアス**：記録は大規模事例・成功例に偏り、事後の語りが機構的に再構成されうる（[応用_集団蜂起 §7](応用_集団蜂起.md)）。
3. **consilience は証明でない**：ドメイン外で予測が当たっても、機構の**到達域の傍証**＝「動物実験の機構がヒト集団のマクロ挙動に届く」の支持であって、係数を当てたのではない。④⑤（蜂起・取り付け）は無参照の独立収束で**強い**、⑥（締め出し）は crowding 経済学が Deci 心理を参照ゆえ**弱い**（[橋渡し §1 独立性階梯](橋渡し_対応表.md)・[応用_動機の締め出し §0](応用_動機の締め出し.md)）。
4. **当たっても外れても §0 の価値**：当たれば reach の証拠、外れれば機構の反証——どちらでも価値②（非自明予測）を果たす。誇張は理論を弱める。
