# 索引 — 検証可能予測カタログ（全予測の横断ハブ）

> **役割**：二層理論が出す**検証可能予測**を1枚に集約し、各予測を〔機構（定理/MA）｜ドメイン｜操作化の所在｜主指標・データ源｜反証の型〕で引けるようにするハブ。各予測の導出は出所 doc に、測定設計は操作化 doc にある——本 doc は**再導出せず索引する**（避重複）。
>
> **§0**：これは予測の**目録**であって結果ではない。各予測の妥当性・反証可能性の中身は各 doc 側にあり、ここでは「どこに何があるか」だけを保証する。consilience は到達域の傍証（[橋渡し §1](橋渡し_対応表.md)）。

---

## 1. 全体像 — 核（背骨）・ドメイン外（到達域）・集団 regime（創発）

予測は3群に分かれる（[橋渡し §1 一致の見取り図](橋渡し_対応表.md)）：

- **核4（機構の背骨・組織内）**：橋渡し §7。神経科学 A × 組織観察 B の内部一致から落ちる。→ 測定設計は [操作化_予測プロトコル.md](操作化_予測プロトコル.md)（操作化②）。
- **ドメイン外10（到達域）**：応用 doc の §6。機構が檻の外（歴史・金融・政策）へ届くか。→ 測定設計は [操作化③_ドメイン外検証.md](操作化③_ドメイン外検証.md)。
- **集団 regime 6（創発）**：多エージェント層 MA-4〜10。個の機構を集計したとき集団に出る regime（5類型創発・規模の壁・階層差・業種適合）。→ 測定設計は [操作化④_集団regime検証.md](操作化④_集団regime検証.md)。
- 観測代理（指標 ↔ パラメータの静的写像）は全予測共通で [操作化_測定接続.md](操作化_測定接続.md)。

> 核4の一部はドメイン外でも再出現する（例：統制可能性の不連続＝組織の叱責でも歴史の弾圧でも）。下表は**機構単位で1行**にし、ドメイン欄に再出現先を併記する（重複計上しない）。

## 4. 操作化の所在（と、まだ操作化していないもの）

- **操作化済（組織内・A/B＋自然実験）**：核4 → [操作化_予測プロトコル.md](操作化_予測プロトコル.md)。
- **操作化済（ドメイン外・史料/event study/自然実験）**：10予測 → [操作化③_ドメイン外検証.md](操作化③_ドメイン外検証.md)。
- **操作化済（集団 regime・cross-org/規模/業種/自然実験）**：6予測 → [操作化④_集団regime検証.md](操作化④_集団regime検証.md)。
- **観測代理（指標↔パラメータの静的写像）**：[操作化_測定接続.md](操作化_測定接続.md)。

→ **20予測すべてが「測定設計（プロトコル）」段階まで到達**（測定接続 → ②組織内 → ③ドメイン外 → ④集団regime の4層）。

**まだやっていない（§0 の誠実さ・残る前線）**：
1. **実施・実データ収集はゼロ**——20予測はいずれも反証可能な設計まで降ろしたが、A/B も自然実験も史料分析も cross-org 調査も**まだ走らせていない**。プロトコルは設計図であって結果ではない。
2. **集団 regime（④）は二重写像が未検証**——sim パラメータ→機構→組織観測 の鎖が他2層より一段仮説的（[操作化④ §0](操作化④_集団regime検証.md)）。
3. 各予測の**統計的検出力・サンプル設計・事前登録**は未着手。

> **本カタログは「全予測を網羅した」とは言えても「検証した」とは主張しない**——設計の網羅であって、実証ではない。
