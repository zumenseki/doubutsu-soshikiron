# 索引 — 検証可能予測カタログ（全予測の横断ハブ）

> **役割**：二層理論が出す**検証可能予測**を1枚に集約し、各予測を〔機構（定理/MA）｜ドメイン｜操作化の所在｜主指標・データ源｜反証の型〕で引けるようにするハブ。各予測の導出は出所 doc に、測定設計は操作化 doc にある——本 doc は**再導出せず索引する**（避重複）。
>
> **§0**：これは予測の**目録**であって結果ではない。各予測の妥当性・反証可能性の中身は各 doc 側にあり、ここでは「どこに何があるか」だけを保証する。consilience は到達域の傍証（[橋渡し §1](橋渡し_対応表.md)）。

---

## 1. 全体像 — 核（背骨）とドメイン外（到達域）

予測は2層に分かれる（[橋渡し §1 一致の見取り図](橋渡し_対応表.md)）：

- **核4（機構の背骨・組織内）**：橋渡し §7。神経科学 A × 組織観察 B の内部一致から落ちる。→ 測定設計は [操作化_予測プロトコル.md](操作化_予測プロトコル.md)（操作化②）。
- **ドメイン外10（到達域）**：応用 doc の §6。機構が檻の外（歴史・金融・政策）へ届くか。→ 測定設計は [操作化③_ドメイン外検証.md](操作化③_ドメイン外検証.md)。
- 観測代理（指標 ↔ パラメータの静的写像）は全予測共通で [操作化_測定接続.md](操作化_測定接続.md)。

> 核4の一部はドメイン外でも再出現する（例：統制可能性の不連続＝組織の叱責でも歴史の弾圧でも）。下表は**機構単位で1行**にし、ドメイン欄に再出現先を併記する（重複計上しない）。

**まだ操作化していない（§0 の誠実さ・将来の宿題）**：多エージェント層 MA-4〜9 が出した**集団 regime の予測**——5類型の創発（MA-4）／再野生化は autonomy 保持の隔離細胞でのみ起きる（MA-5）／協力は容量 D の壁で相転移崩落（MA-6）／層は off-diagonal が最適（MA-7）／最適 regime は業種(v×ec)の関数で勝ち文化の移植は失敗（MA-9）——は、まだ反証可能な測定プロトコルへ降ろしていない（[橋渡し §6・§8](橋渡し_対応表.md)・[sim/README.md](../sim/README.md)）。これらは sim 内で機構から創発させた段階で、実組織データでの操作化は未着手。**本カタログは「全予測を網羅した」と主張しない**。
