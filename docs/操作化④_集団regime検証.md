# 操作化④ — 集団 regime 予測の反証化（多エージェント MA-4〜10）

> **役割**：[索引_検証可能予測.md §4](索引_検証可能予測.md) が「まだ操作化していない」と明示した、多エージェント層 MA-4〜10 の**集団 regime 予測**を反証可能な形へ降ろす。操作化② が**組織内・個人レベル**（橋渡し §7 の4予測）、操作化③ が**ドメイン外・歴史/金融**（蜂起・取り付け・締め出し）を扱ったのに対し、本 doc は**集団・組織レベル**——複数エージェントの集計から創発する文化 regime——の予測を、cross-org 比較・規模閾値・隔離細胞/制度導入の自然実験・業種分類で操作化する第三レジスタ。MA-1/8（恐怖伝播/蜂起カスケード）は既に[操作化③](操作化③_ドメイン外検証.md)で扱ったので除外。
>
> **§0 堅持（二重に重い・最優先）**：本 doc の予測は **sim で機構から創発させた段階**のもの（[sim/README.md](../sim/README.md) MA-4〜10）。よって写像は **二重に未検証**：(1) sim パラメータ（D, λ, v, ec, c_F, kconf …）→ 機構、(2) 機構 → 実組織の観測量。操作化②③の「観測代理→パラメータ」写像の上に、さらに「sim 構成→機構」の仮説が乗る。加えて**各 sim の §0 留保をそのまま継承する**——「盲目的クラスタリングで丁度5型とは主張しない」（MA-4）／「faction の内容・権力ゲームは非モデル化」（MA-6/7）／「2軸は業種の最小戯画」（MA-9/10）／「特定組織の最適規模・最適設計を主張しない」。本 doc は**測定の設計**であって結果でも処方箋でもない（[正本 §0](正本_ミクロ機構.md)・[橋渡し §0](橋渡し_対応表.md)）。

## 1. なぜ集団 regime の操作化は二重に難しいか

操作化②（個人・組織内）は介入で、③（ドメイン外）は史料・event study で予測を試せた。④の対象は**集団の創発 regime**——5類型・再野生化・規模の壁・階層差・業種適合——で、単一の介入や1事象では出ない。テストの単位は **cross-org 断面**（多数の組織/チームを横断して regime と帰結を突き合わせる）か、**規模・業種という構造変数**、または**隔離細胞・制度導入の自然実験**になる。

そして §0 が重い：これらは sim が機構から**創発**させた予測で、「sim の図がこう出た」と「実組織でこう出る」の間に、写像の鎖が二重にかかる。だから本 doc の反証条件は**保守的**に置く——「sim の数値（0.94 とか 1.4D とか）が実組織で当たる」ではなく、**通俗説と分岐する定性的な構造**（連続でなく壁／一律でなく差別化／普遍でなく業種依存）が出るか否かを問う。数値の一致は主張しない。

## 2. 共通フォーマット（集団版・6項）

操作化②③の6項を集団レベルへ。**④が「同定戦略」＝cross-org 断面／規模・業種という構造変数／隔離細胞・制度導入の自然実験**になる。

| 項 | 中身 | 集団版での注意 |
|---|---|---|
| **① 機構的主張** | どの MA／sim figure から落ちるか | sim の §0 留保を併記（過剰主張回避） |
| **② 操作的定義** | 独立（構造変数）・従属（集団帰結）を観測量で | regime/同調/容量D/業種(v,ec) を組織観測へ |
| **③ データ源・指標** | cross-org HR/性能・規模・業種分類 | 診断(/shindan 4軸)は粗い代理 |
| **④ 同定戦略** | 断面比較／規模・業種勾配／自然実験 | 単一組織でなく**多数の組織/チーム**が単位 |
| **⑤ 反証条件** | **定性構造**が出ないと誤り（数値一致は問わない） | 連続/一律/普遍 が出れば機構の分岐は反証 |
| **⑥ 交絡と限界** | 対抗仮説＋sim §0 留保の継承 | 業種・規模・歴史の交絡、指標の束 |

> **横断の交絡（④固有）**：(a) **組織は無作為割付できない**——regime・規模・業種は内生（成功した組織が特定 regime を採る逆因果）。(b) **指標が束**——morale・innovation・cohesion は複数パラメータの合成（[bcd §2 交絡](操作化_測定接続.md)）。(c) **sim の最小モデル性**——faction の中身・権力ゲーム・業種の多次元性は非モデル化ゆえ、本 doc もそこは問わない。

## 3. MA-4 — 5類型は (随伴C × 情動A) regime として創発するか

**①機構的主張**：[MA-4](../sim/multiagent_archetypes.py)。経営者の (C,A) ノブ（fear/f/kconf/ineq/omega/c）を振ると、5動物類型が **distinct で安定な集団 regime** として創発し、5指標 fingerprint（morale/innovation/perf/split/helpless）で分離する（wolf 高革新健全／ant 規範固着／chimp morale分断・政治／bonobo slack／hyena 崩落+burnout）。**§0：盲目的クラスタリングで丁度5個とは主張しない**——プリセット5点での創発。

**②操作的定義**
- *独立 = 組織の (C,A) regime*：随伴 C（行動→結果の密結合度／一律処遇か）・情動 A（恐怖点灯・同調圧 kconf・不平等可視性 ineq・社会比較 omega）を組織アンケート/制度から推定。
- *従属 = 5指標 fingerprint*：**morale**（エンゲージ・離職逆）／**innovation**（新practice採用率）／**perf**／**split**（morale分散＝厚遇↑/不遇↓ の二極化）／**helpless**（撤退ラッチ＝行動停止率・[bcd §2](操作化_測定接続.md) の恐怖/学習代理）。

**③データ源・指標**：cross-org の HR データ（離職・エンゲージ）・イノベ指標・診断（[/shindan 4軸](操作化_測定接続.md)は粗い代理）。

**④同定戦略**：多数組織を (C,A) 入力で層別し、fingerprint が **distinct なクラスタ（5署名に対応）に落ちるか／連続体か**を見る（断面クラスタリング）。**「ちょうど5個」は検定しない**——検証するのは「(C,A) が fingerprint を予測し、署名どうしが分離・安定する」こと。

**⑤反証条件**（事前登録）
- (C,A) regime が fingerprint を**予測しない**（入力と出力が無相関）→ 反証。
- fingerprint が**滑らかな連続体**で、wolf/ant/chimp/bonobo/hyena に対応する**分離・安定した塊が出ない**→「distinct regime として創発」は反証。
- regime が**時間で不安定**（同じ (C,A) で揺れ続ける）→ アトラクタ＝安定 regime の主張は反証。

**⑥交絡と限界**
- 組織文化は業種・規模・歴史と交絡（regime を入力で揃えにくい）。fingerprint 指標は束（[bcd §2](操作化_測定接続.md)）。
- **過剰主張回避**：本予測は「5型が**唯一の自然分割**」ではない（[MA-4 §0](../sim/README.md)）。「(C,A) で distinct regime が出る」までが射程。faction の中身は非モデル化。

## 4. MA-5 — 再野生化は autonomy 保持の隔離細胞でのみ起きるか

**①機構的主張**：[MA-5](../sim/multiagent_rewilding.py)。Stage5 硬直（status quo ロック）からの脱出は、同調を「全体的に少し緩める」号令では起きず（adoption 0.00）、**autonomy を保った臨界質量の隔離細胞**でのみ規範が反転する（0.94）。細胞を多数派へ再吸収すると人気に飲まれ元へ戻る（0.00）。＝[定理B](正本_ミクロ機構.md)「外生注入だけが無力感アトラクタの脱出路」の集団版。

**②操作的定義**
- *独立 = イノベ注入モード*：(a) **全体微緩**＝トップダウンの「変革せよ」号令（同調を全社で少し下げる）／(b) **保護隔離 unit**＝前例/process の届かない autonomy を持つ臨界質量の部署（skunkworks・出島）／(c) **再吸収**＝隔離 unit を後から本体へ統合。
- *従属 = 新 practice の全社 adoption*（時系列）。＋**細胞サイズ → 最終 adoption**（臨界質量 ≈0.30 の閾値）。

**③データ源**：skunkworks/新規事業 unit を作った組織 vs トップダウン変革プログラムの組織。新 practice が全社へ波及したか。再吸収イベントの前後。

**④同定戦略**：比較事例/自然実験——3モードの adoption 軌跡を比較。**用量反応**＝隔離 unit のサイズ（多数派からの遮断度・autonomy 度）と最終 adoption の関係（token な数%では足りず臨界質量が要る、という閾値）。

**⑤反証条件**（事前登録）
- **全体微緩（号令）が隔離細胞と同等に adoption する**→「autonomy 隔離が要る」は反証。
- autonomy の有無が adoption を分けない／**再吸収しても新規範が残る**→ 「autonomy が要石」は反証。
- token skunkworks（極小 unit）で十分波及する（**臨界質量の閾値が無い**）→ 反証。

**⑥交絡と限界**
- 選択効果（autonomy を与える組織は他も違う）。新 practice 自体の優劣（autonomy でなく中身が効いた可能性）→ practice の質を揃えた比較が要る。
- 「autonomy」「再吸収」の操作的定義（何をもって保護/統合か）。sim §0：**唯一解性は主張しない**——細胞が小さい/多数派同調が強いと脱出しない（[MA-5 §0](../sim/README.md)）。

## 5. MA-6 — 協力は規模の壁で相転移的に崩落するか（壁 ∝ 容量 D）

**①機構的主張**：[MA-6](../sim/multiagent_dunbar.py)。有界な社交容量 D（各自が監視/信頼できる相手の上限）で、規模 N が増えると評判被覆 `coverage=min(1, D/(N−1))` が下がり、監視外では裏切りが罰されない。N が壁を越えると協力（cohesion）が **相転移的に崩落**（連続的希薄化でなく鋭い壁）。壁は普遍数「150」でなく **容量 D に比例**（≈1.4D）。

**②操作的定義**
- *独立 = 規模 N と容量 D*：N＝チーム/部署の人数。D＝**評判が届く範囲**（互いの行動を観察・信頼できる相手数＝評判システム・コミュニケーション密度の代理）。
- *従属 = cohesion*：協力率／フリーライド・裏切りの頻度／**最大協力クラスタのサイズ**（断片化の指標）。

**③データ源**：チーム/部署サイズ × 協力指標（cross-team 断面）。D の代理＝評判可視化の仕組み（小規模相互評価・透明性ツール・対面密度）。

**④同定戦略**
- *規模勾配*：cohesion を N に対してプロット——**滑らかな減衰でなく、ある N で鋭い段差（相転移）**が出るか。
- *壁 ∝ D の検証*：D の異なる組織間で**壁の位置が D に比例して動く**か（評判インフラが厚い組織ほど壁が大きい N に出る）。「150」固定でないこと。

**⑤反証条件**（事前登録）
- cohesion が規模に対し**滑らかに低下**（**壁/閾値が無い**）→「相転移的崩落」は反証。
- 壁が **D によらず一定（≈150 固定）**→「壁 ∝ 容量 D」は反証（普遍定数説が支持）。
- D（評判被覆）と cohesion・壁位置に**関係が無い**→ 評判被覆機構は反証。

**⑥交絡と限界**
- 規模は年齢・形式化・業種と交絡（大組織は他も違う）→ 規模以外をマッチ。D の独立測定が難しい（評判可視化の代理の妥当性）。
- 「鋭い壁」判定には規模の**細かい分解能**が要る。sim §0：崩落後の「分断・政治(chimp)」は giant component 消失で示すが **faction の中身・権力ゲームは非モデル化**（[MA-6 §0](../sim/README.md)）。特定組織の「最適規模」は主張しない。

## 6. MA-7 — 層は off-diagonal（差別化）が最適で、現場 autonomy が要るか

**①機構的主張**：[MA-7](../sim/multiagent_hierarchy.py)。org 性能 P＝現場探索 E × 管理調整 Co。一律 regime は必ず片層を犠牲にし劣る（一律 wolf 0.21=調整欠／一律 ant 0.00=探索欠）。最適は対角線（一律）でなく **off-diagonal**（現場低同調 × 管理高同調＝0.47/相図最適0.80）。さらに top-down 結合 λ が強い（管理の同調が現場へ漏れ＝process 押し付け）と現場探索が死に P 崩落（E: 0.76→0.00）。

**②操作的定義**
- *独立 = 層の同調差 と top-down 結合 λ*：現場同調 c_F（現場の手順統一/裁量の無さ）と管理同調 c_B（管理層の整列度）の**差**。λ＝管理の process が現場へどれだけ押し付けられるか（標準手順の強制度）。
- *従属 = 性能 P と分解 E・Co*：**E**＝現場の新 practice 採用率（探索）／**Co**＝管理層の整列・合意（調整）／P＝両者の積。

**③データ源**：cross-org——現場の autonomy/同調 と 管理の標準化 を制度・アンケートで測り、process 押し付け度と性能を突き合わせる。

**④同定戦略**
- *断面 × 性能*：**層を差別化した組織（現場低同調 × 管理高同調）が一律文化の組織を上回る**か。
- *結合 λ*：top-down の process 強制が強い組織ほど**現場探索 E が低い**か（組織内/組織間）。

**⑤反証条件**（事前登録）
- **一律文化の組織が差別化組織と同等に高性能**→「off-diagonal が最適」は反証。
- 層の同調差と性能に**関係が無い**／差別化が**不利**→ 反証。
- 強い top-down 結合が**現場探索を下げない**→「現場 autonomy が要る（MA-5 と連結）」は反証。

**⑥交絡と限界**
- 層ごとの同調・autonomy の測定が難しい（両層を別々に測る必要）。性能は多因子。
- sim §0：P=E×Co は**層タスクの最小モデル**で、faction/権力・経営層の意思決定の中身は非モデル化（[MA-7 §0](../sim/README.md)）。特定企業の「最適な階層設計」は主張しない。

## 7. MA-9 / MA-10 — 最適 regime・最適 org 設計は業種 (v×ec) の関数か

> MA-9（業種で最適 regime が違う）と MA-10（業種で最適 org 設計＝現場同調が違う）は同じ業種2軸に乗るので一括。

**①機構的主張**
- [MA-9](../sim/multiagent_industry.py)：業種を **変動性 v**（正解 practice が移る速さ＝探索要求）× **失敗コスト ec**（非標準への罰＝標準化要求）で定義すると、**最適 regime は (v, ec) の関数＝普遍ベストは無い**（高 v→wolf／高 ec→ant が地図を二分・健全2型で53%）。**勝ち文化の移植は逆コーナーで regret 大**。
- [MA-10](../sim/multiagent_industry_hierarchy.py)：そこに階層を入れると **現場の最適同調 c_F\* も業種の関数**。現場が wolf でいられるのは「変動が速く・失敗が安い」象限（IT/創造）だけで、低変動×高失敗コスト（航空/原子力/医療）では**現場も標準化**（c_F\*↑・差別化Δ 1.93→0.00 へ圧縮）。差別化圧縮の**主因は変動性 v**（ec は副次）。

**②操作的定義**
- *独立 = 業種の (v, ec)*：v＝正解 practice の移動速度（R&D 集約度・製品/技術の陳腐化速度）／ec＝非標準・失敗の罰（規制・安全クリティカル度・事故コスト）。
- *従属*：(MA-9) その業種の**高業績企業を特徴づける regime**（wolf/ant/…）／**移植 regret**（勝ち文化を逆象限業種へ持ち込んだ時の業績低下）。(MA-10) 高業績企業の**現場標準化度 c_F\*** と **差別化Δ**（現場-管理の同調差）。

**③データ源**：cross-industry の企業業績 × 文化型／業種を (v, ec) で分類（R&D 比率・規制強度）／文化を業種跨ぎで移植した事例（M&A・経営者招聘で別業種の流儀を持ち込んだケース）。

**④同定戦略**
- *(v×ec) 地図*：勝ち regime を (v, ec) グリッドに置く——**高 v×低 ec で wolf、低 v×高 ec で ant** が出るか（地図の非一様性）。
- *移植 regret*：勝ち文化を逆象限業種へ持ち込んだ企業/部門が**劣化**するか（自業種では regret≈0）。
- *(MA-10) 現場標準化*：**高 stakes（低 v×高 ec）業種の高業績企業ほど現場が標準化**（c_F\* 高・Δ 小）か。「現場=wolf 常に」が高 stakes で**成り立たない**こと。

**⑤反証条件**（事前登録）
- **単一 regime が全業種で勝つ**（普遍ベストが在る）／勝ち地図に **(v,ec) 構造が無い**→ MA-9 は反証（ベストプラクティス唯一説が支持）。
- **移植が劣化しない**（勝ち文化はどの業種でも通用）→「移植は失敗」は反証。
- **最適 現場標準化が業種で一定**／高 stakes 業種でも「現場=wolf」が最適→ MA-10 は反証。差別化圧縮の主因が v でなく ec なら、その nuance は部分反証。

**⑥交絡と限界**
- 業種分類が粗い（実業種は多次元＝[MA-9 §0](../sim/README.md) の「2軸は最小戯画」）。文化型の測定。生存バイアス（観測できるのは生き残った企業）。移植事例は**移植の理由**と交絡（なぜその文化を入れたか）。
- sim §0：「普遍は無い」という**構造**を示すレンズであって、特定業種の「正しい型/org 設計」を当てるものではない。高 stakes の「現場標準化」は本モデルの含意で、**安全文化の現実の設計指針ではない**（[MA-10 §0](../sim/README.md)）。

## 8. §0 — この集団 regime プロトコルの限界

操作化②③の限界に、**集団・sim 創発レベル固有の上乗せ**：

1. **二重写像が未検証**：本 doc の予測は sim が機構から創発させたもの。「sim パラメータ→機構」と「機構→組織観測」の**両方の写像が未検証**。操作化②③より一段、土台が仮説的。だから反証条件は数値一致でなく**定性構造**（連続でなく壁／一律でなく差別化／普遍でなく業種依存）に置いた。
2. **各 sim の §0 留保を継承**：「5型が唯一の自然分割とは言わない」（MA-4）／「再野生化の唯一解性は主張しない」（MA-5）／「faction の中身・権力ゲーム・最適規模は非モデル化」（MA-6/7）／「業種2軸は最小戯画・特定業種の正解 org 設計は当てない」（MA-9/10）。本 doc もそこは問わない。
3. **組織は無作為割付できない**：regime・規模・業種は内生（逆因果＝成功が特定 regime を採らせた可能性）。cross-org 断面は交絡だらけで、自然実験（隔離細胞・制度導入・業種跨ぎ移植）で割付の外生性に近づけるのが精一杯。
4. **当たっても外れても §0 の価値**：当たれば機構の集団レベルへの reach の傍証、外れれば反証——どちらでも価値②（非自明予測）。誇張は理論を弱める。
5. **処方箋ではない**：特に MA-10 の「高 stakes で現場標準化」は**モデルの含意**であって、安全クリティカル業種の設計指針として読んではならない。
