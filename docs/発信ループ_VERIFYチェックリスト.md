# 発信ループ VERIFY チェックリスト（運用版）

> [発信ループ設計.md](発信ループ設計.md) §6（VERIFY評価関数）を、実作業でそのまま使える形にしたもの。
> 各ループの VERIFY フェーズで上から確認。**1つでも ✗ なら ITERATE に戻す**（同フェーズ3回失敗で人間にエスカレーション）。
>
> 印：**🤖=自動で落とせる**（`scripts/verify-article.py` 等）／**👁=人間が§0観点で判断**（自動採用しない）。
> 思想：自動は「疑わしきを上げる adversarial な採点」。最終の理論判断は人間が握る（[CLAUDE.md](../CLAUDE.md) §0）。

---

## 0. 自動採点の使い方（記事系）

```powershell
python -X utf8 scripts/verify-article.py site\src\content\articles\<slug>.md
# 複数: ... articles\*.md
```
- **FAIL** … frontmatter 欠落など確実な違反。直してから先へ。
- **WARN** … 誇張/断定の疑い語・法令注記漏れ・比喩語ゼロ。👁 で確認。
- **INFO** … 二層素材（式記号/比喩語の有無）・§0注記の気配・分量。判断材料。

> スクリプトは「動物行動学」固定タグを**チェックしない**（＝note入稿時に付与する運用・既存記事への遡及は人間別タスク）。下表 B-2 で人間が担保。

## A. 全ループ共通（§0・ブランド核）

| | 項目 | 印 |
|---|---|---|
| A-1 | **誇張禁止**：「実測で当たっている」と読める表現がない（仮説生成ツール） | 🤖WARN→👁 |
| A-2 | **二層表記**：Layer1は式で語る／Layer2は「比喩」「レンズ」と明示。比喩を式に薄めていない | 🤖INFO→👁 |
| A-3 | **断定回避**：特定企業/単一原因を断定していない（末尾§0注記あり） | 👁 |
| A-4 | **ブランド核**：動物・生態系の比喩が一般的tipsに薄まっていない（比喩語ゼロは要注意） | 🤖WARN→👁 |
| A-5 | **法令・数値**：労基法/最低賃金等を扱うなら出典＋「変わりうる」注記あり | 🤖WARN→👁 |

## B. 記事生成ループ（L-A）

| | 項目 | 印 |
|---|---|---|
| B-1 | frontmatter（title/description/pubDate/tags）完備 | 🤖FAIL |
| B-2 | **note入稿時に `#動物行動学` を固定枠で含める**（2026-06-15規約） | 👁（入稿時） |
| B-3 | 表題フックが [note_表題フック規約.md](note_表題フック規約.md) に沿う | 👁 |
| B-4 | **note整形QA**：h2＝見出しマーカー全件・**emptyH2:0**・fig:0・chars が Step5 と一致 | 🤖（入稿後・DOM） |
| B-5 | 引用/リスト/hr を自動付与していない（note-publish SKILL「やらないこと」） | 🤖（入稿後） |
| B-6 | 既存記事と内容が重複していない（同じ「一致」を二度書かない） | 👁 |

🔴 **人間ゲート**：アイキャッチ手動／会員ゲート設定／**公開ボタンは人間**（BAN回避）。

## C. 動画生成ループ（L-B）

| | 項目 | 印 |
|---|---|---|
| C-1 | `npx hyperframes lint` が **0 error** | 🤖 |
| C-2 | `inspect`（両方）が **0 issue** | 🤖 |

| C-7 | commit はソースのみ（mp4/mp3/srt/bgm/frames 除外） | 🤖（git） |

🔴 **人間ゲート**：**YouTubeアップロードは人間**／概要欄4点（チャプター・記事リンク・note導線・§0注）／**push前に gh account 切替**。

## E. ネタ発掘ループ（L-D）

| | 項目 | 印 |
|---|---|---|
| E-1 | 既存「一致」（蜂起/取り付け/締め出し/子育て）と被っていない | 👁 |
| E-2 | 候補ごとに対応機構（恐怖/報酬/学習/集計・定理A–D）の写像が立つ | 👁 |
| E-3 | **比喩を式に薄めていないか／本当に機構から導けるか・通俗経営論に後退していないか** | 👁（最厳） |

🔴 **人間ゲート**：**新しい「一致」の採用判断は人間**（誇張は理論を弱める＝§0）。ループは候補を出すだけ。
