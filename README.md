## 現場どうぶつ診断

建設現場などの「**部下が動かない・若手が辞める・ヒヤリが上がらない**」の背景を、**恐怖・報酬・学習・連携**の4軸で見える化する自己点検ツール。

- 15問・60秒 → 4軸の健全度 → 進化Stage（狩猟〜硬直）→ 7つの組織タイプ → 所見・弱点・打ち手
- 結果は「組織の自己点検」であり、個人の評価でも、医療・心理の診断でもない

## 二層アーキテクチャ

| 層 | 内容 |
|---|---|
| **Layer1（正本・ミクロ）** | 学習＝随伴×予測誤差（Rescorla-Wagner）。恐怖と報酬は非対称・直交の二エンジン。定理A–D。 |
| **Layer2（比喩・マクロ）** | 5類型（オオカミ／アリ／チンパン／ボノボ／ハイエナ）。4ダイヤル・進化5ステージ。 |
| **橋渡し** | 4ダイヤル ↔ 2エンジン＋学習＋集計。5類型を機構の言葉へ写像。 |

> 比喩を式に薄めず、比喩を式が説明する構図を保つ（二層表記ルール）。
