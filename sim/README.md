# sim — 理論のストレステスト（シミュレーション）

各シミュレーションが「[理論](../docs/正本_ミクロ機構.md)のどの主張を検証しているか」を明記する。
再現性のため乱数シードは固定（`config.py` の `seed`）。新規依存なし（numpy / matplotlib のみ）。

## theorem_b_controllability.py — 定理B（統制可能性の崖）

### 検証する主張
> 同じ強度の罰でも、統制可能なら適応的回避、統制不能（恣意的）なら無力感。
> 両者は連続的グラデーションでなく **質的な不連続** を示すはず。
> 効くのは「どれだけ厳しいか」ではなく「コントロールできるか」。
> （[正本 §6-7](../docs/正本_ミクロ機構.md)、[橋渡し §1③](../docs/橋渡し_対応表.md)）

### モデル（最小・Mowrer 回避学習設定）
- 状態 `Ĝ∈[0,1]`：一般化統制可能性の信念。
- 行動ゲート `P(act)=σ(β(Ĝ−θ))`。さらに `Ĝ<θ_giveup` で **撤退ラッチ**（自発行動を完全停止）。
- 環境2条件：
  - **統制可能** … 行動すれば罰を回避できる（`P(罰|行動)≈0`、行動しなければ強度どおり）。
  - **統制不能** … 罰は行動に依存しない（Seligman の yoked-control 設計）。
- **自己封止更新（要石）**：Ĝ は「**行動した試行でのみ**」観測統制性 `g_trial∈{0,1}` へ更新。
  - 上方更新は **帰属ゲート**（現在のĜ）でゲート：`Ĝ ← Ĝ + λ·Ĝ·(g_trial−Ĝ)`（[§4 修正項1](../docs/正本_ミクロ機構.md)）。無力時は成功を自分に帰属できず climb しにくい。
  - 下方更新は素直に効く：`Ĝ ← Ĝ + λ·(g_trial−Ĝ)`（悪い証拠は損失側で重い）。

### 不連続は「創発」させる（ハードコードしない）
段差関数を結果（outcome）に直接埋め込まない。崖は次のフィードバックループから **創発** する：
統制不能 → 行動しても罰 → `g_trial=0` → Ĝ 低下 → 撤退ラッチ作動 → 自発サンプリング停止 → Ĝ 更新凍結 → **吸収的な低活動アトラクタ**。
撤退ラッチは §1 の「回避は当の状況を二度と経験しない＝データを自ら遮断する」を素直に実装したもの。外生注入（行動強制）だけがこれを破れる。
Fig2 の不連続は依然 contingency（統制性・強度）から出ており、結論を仕込んでいない（[§0](../docs/正本_ミクロ機構.md)）。

### 実行
```powershell
python sim/theorem_b_controllability.py
```
- cwd に依存しない（スクリプトが自分の場所を基準に動く）。
- 出力 PNG は `sim/out/`（`.gitignore` 済み。再現は seed で担保）。
- stdout に検証用サマリ（最終Ĝ、崖の位置、回復の有無）を表示。

### 出力（3枚）
| ファイル | 何を示すか |
|---|---|
| `out/fig1_timeseries.png` | 同一強度の罰でも、Ĝ・行動率が **高位安定（可能）vs 崩落（不能）** に分岐 |
| `out/fig2_intensity_sweep.png` | 罰強度を連続に振っても、可能は平坦高・不能は **崖**。不連続を駆動するのは強度でなく統制性 |
| `out/fig3_recovery.png` | 不能で崩落後、可能に戻しても **自然回復しない**。外生「行動強制（確実に勝てる経験）」の注入で初めて脱出 |

### 結果（seed=20260604 での観測値）
- **Fig1**：同強度の罰 intensity=0.85 で、最終 Ĝ＝controllable **0.94** / uncontrollable **0.29**、行動率 1.00 / 0.00。
- **Fig2**：最終Ĝの最大勾配 |dĜ/dI|＝controllable **0.08** / uncontrollable **3.40**。崖は uncontrollable 側にのみ出る（不連続は強度でなく統制性が駆動）。
- **Fig3**：Phase1→0.29（崩落）／ Phase2→0.29（**自然回復しない**）／ Phase3→0.94（外生注入で脱出）。

これは「式が定理Bを再現するか」の確認であって、組織データへのフィットではない（[§0](../docs/正本_ミクロ機構.md)）。

## theorem_a_reward_withdrawal.py — 定理A（報酬撤回 = 罰）

### 検証する主張
> u は参照点依存で κ>1。R_eff を ρ 未満に下げると δ は負かつ κ倍に増幅され、恐怖系の動態（τ↓）を呼ぶ。
> 報酬の撤回・相対的減額は「baseline に戻る」ではなく破壊エンジンへ押し込む別カテゴリ。
> **維持できない報酬は据え付けてはいけない。**（[正本 §4 修正項2, §6 定理A](../docs/正本_ミクロ機構.md)）

### 3条件
- **never** … 報酬を上げない（baseline のまま）
- **sustained** … 上げて維持する（撤回しない）
- **withdraw** … 上げてから撤回する（baseline へ戻す）

### 機構
- 参照点 ρ が経験報酬へ適応（快楽の踏み車）。引き上げを維持すると ρ も上昇。
- 撤回時 R<ρ → `u=κ(R−ρ)` で負の δ が κ倍に増幅 → V 急落。
- 負の損失 δ が恐怖エンジンを起動し τ を狭める（V には書かない）。
- 結果は「baseline 復帰」でなく、never 条件より一時的に悪化する（破壊エンジン）。

### 実行
```powershell
python sim/theorem_a_reward_withdrawal.py
```
既定は決定論（`reward_noise=0`）。`reward_noise>0` にすると確率的になり seed が効く。

### 出力（3枚）
| ファイル | 何を示すか |
|---|---|
| `out/figA1_timeseries.png` | V(t)・δ(t)。撤回時のみ κ倍の負δ → V が baseline 以下へ |
| `out/figA2_fear_tau.png` | τ(t)。撤回条件でのみ恐怖エンジンが起動し τ 崩壊（探索狭窄） |
| `out/figA3_asymmetry.png` | 損失/利得 ≈ κ の非対称 ＋ Phase C 最小V（withdraw < never） |

### 結果（seed=20260604・決定論）
- δ：raise **+1.00**（非増幅）／ withdraw **−2.25**（κ倍）、比 **2.25 = κ**。
- 最小V（t1以降）：never 0.00 ／ sustained 0.00 ／ withdraw **−1.49**（＝ baseline より悪い）。
- τ：withdraw 最小 **0.13**（baseline 1.0）＝ 探索の崩壊。

### 非目標
多エージェント化しない／実データへの係数フィットをしない（[§0](../docs/正本_ミクロ機構.md)）。
