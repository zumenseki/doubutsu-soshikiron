## theorem_b_controllability.py — 定理B（統制可能性の崖）

### 検証する主張
> 同じ強度の罰でも、統制可能なら適応的回避、統制不能（恣意的）なら無力感。
> 両者は連続的グラデーションでなく **質的な不連続** を示すはず。
> 効くのは「どれだけ厳しいか」ではなく「コントロールできるか」。
> （[正本 §6-7](../docs/正本_ミクロ機構.md)、[橋渡し §1③](../docs/橋渡し_対応表.md)）

### モデル（最小・Mowrer 回避学習設定）
- 状態 `Ĝ∈[0,1]`：一般化統制可能性の信念。
- 行動ゲート `P(act)=σ(β(Ĝ−θ))`。さらに `Ĝ<θ_giveup` で **撤退ラッチ**（自発行動を完全停止）。
- 環境2条件：
  - **統制可能** … 行動すれば罰を回避できる（`P(罰|行動)≈0`、行動しなければ強度どおり）。
  - **統制不能** … 罰は行動に依存しない（Seligman の yoked-control 設計）。
- **自己封止更新（要石）**：Ĝ は「**行動した試行でのみ**」観測統制性 `g_trial∈{0,1}` へ更新。
  - 上方更新は **帰属ゲート**（現在のĜ）でゲート：`Ĝ ← Ĝ + λ·Ĝ·(g_trial−Ĝ)`（[§4 修正項1](../docs/正本_ミクロ機構.md)）。無力時は成功を自分に帰属できず climb しにくい。
  - 下方更新は素直に効く：`Ĝ ← Ĝ + λ·(g_trial−Ĝ)`（悪い証拠は損失側で重い）。

### 不連続は「創発」させる（ハードコードしない）
段差関数を結果（outcome）に直接埋め込まない。崖は次のフィードバックループから **創発** する：
統制不能 → 行動しても罰 → `g_trial=0` → Ĝ 低下 → 撤退ラッチ作動 → 自発サンプリング停止 → Ĝ 更新凍結 → **吸収的な低活動アトラクタ**。
撤退ラッチは §1 の「回避は当の状況を二度と経験しない＝データを自ら遮断する」を素直に実装したもの。外生注入（行動強制）だけがこれを破れる。
Fig2 の不連続は依然 contingency（統制性・強度）から出ており、結論を仕込んでいない（[§0](../docs/正本_ミクロ機構.md)）。

### 実行
```powershell
python sim/theorem_b_controllability.py
```
- cwd に依存しない（スクリプトが自分の場所を基準に動く）。
- 出力 PNG は `sim/out/`（`.gitignore` 済み。再現は seed で担保）。
- stdout に検証用サマリ（最終Ĝ、崖の位置、回復の有無）を表示。

### 出力（3枚）

| `out/fig2_intensity_sweep.png` | 罰強度を連続に振っても、可能は平坦高・不能は **崖**。不連続を駆動するのは強度でなく統制性 |

## theorem_a_reward_withdrawal.py — 定理A（報酬撤回 = 罰）

### 検証する主張
> u は参照点依存で κ>1。R_eff を ρ 未満に下げると δ は負かつ κ倍に増幅され、恐怖系の動態（τ↓）を呼ぶ。
> 報酬の撤回・相対的減額は「baseline に戻る」ではなく破壊エンジンへ押し込む別カテゴリ。
> **維持できない報酬は据え付けてはいけない。**（[正本 §4 修正項2, §6 定理A](../docs/正本_ミクロ機構.md)）

### 3条件
- **never** … 報酬を上げない（baseline のまま）
- **sustained** … 上げて維持する（撤回しない）
- **withdraw** … 上げてから撤回する（baseline へ戻す）

### 機構
- 参照点 ρ が経験報酬へ適応（快楽の踏み車）。引き上げを維持すると ρ も上昇。
- 撤回時 R<ρ → `u=κ(R−ρ)` で負の δ が κ倍に増幅 → V 急落。
- 負の損失 δ が恐怖エンジンを起動し τ を狭める（V には書かない）。
- 結果は「baseline 復帰」でなく、never 条件より一時的に悪化する（破壊エンジン）。

### 実行
```powershell
python sim/theorem_a_reward_withdrawal.py
```
既定は決定論（`reward_noise=0`）。`reward_noise>0` にすると確率的になり seed が効く。

### 出力（3枚）
| ファイル | 何を示すか |
|---|---|
| `out/figA1_timeseries.png` | V(t)・δ(t)。撤回時のみ κ倍の負δ → V が baseline 以下へ |
| `out/figA2_fear_tau.png` | τ(t)。撤回条件でのみ恐怖エンジンが起動し τ 崩壊（探索狭窄） |
| `out/figA3_asymmetry.png` | 損失/利得 ≈ κ の非対称 ＋ Phase C 最小V（withdraw < never） |

### 結果（seed=20260604・決定論）
- δ：raise **+1.00**（非増幅）／ withdraw **−2.25**（κ倍）、比 **2.25 = κ**。
- 最小V（t1以降）：never 0.00 ／ sustained 0.00 ／ withdraw **−1.49**（＝ baseline より悪い）。
- τ：withdraw 最小 **0.13**（baseline 1.0）＝ 探索の崩壊。

## theorem_c_undermining.py — 定理C（アンダーマイニング罠）

### 検証する主張
> f が x_ext より速く立ち上がる領域で dR_eff/dR_ext < 0。内在価値の高い（I₀大）役割では、
> 関与に対する顕著な金銭報酬は実効動機を下げる。
> → 危険な役割（高I₀）と安全な報酬形態（情報的・予期せぬもの, f≈0）を式が指定する。
> （[正本 §4 修正項3, §6 定理C](../docs/正本_ミクロ機構.md)）

### 機構
`R_eff = D·(w·x_ext) + I₀·(1 − f(x_ext))`。f は内在価値の抑制関数。
統制的・有形・予期される報酬 → f 大（ここでは `f=f_max·x/(x+x_half)`、小 x で急峻）。
情報的・予期せぬ報酬 → f≈0。外発項が増えるより速く `I₀·f` が内発を削るとき `dR_eff/dx_ext<0`。

### 3ケース
- **high I0, controlling** … 内在価値の高い役割に統制的（金銭）報酬 → 罠
- **low I0, controlling** … 削る内発が小さく罠は出ない
- **high I0, informational** … f≈0 で内発を削らず罠は出ない

### 実行 / 出力（3枚・決定論）
```powershell
python sim/theorem_c_undermining.py
```
| ファイル | 何を示すか |
|---|---|
| `out/figC1_reffective.png` | R_eff(x_ext)。高I₀×統制的 は no-reward baseline を下回る（罠） |
| `out/figC2_derivative.png` | dR_eff/dx_ext。高I₀×統制的 のみ符号が負へ |
| `out/figC3_region.png` | (I₀, x_ext) 平面で逆効果領域（赤）＝式が高I₀役割を危険と指定 |

### 結果
- x_ext→0 の限界効果：high-I0 controlling **−3.50**（逆効果）／ low-I0 +0.33 ／ informational +1.00。
- undermining 閾値 **I₀>0.44** で x_ext→0 から逆効果。
- 罠：R_eff 2.00 → 最小 **1.50** @ x_ext=0.45（無報酬より悪い）、baseline 復帰に x_ext≈1.40。

## theorem_d_compound_cost.py — 定理D（恐怖の複合コスト）

### 検証する主張
> 恐怖は τ↓・k↑・習慣化を同時に起こす。一軸の「動機の減少」ではなく独立3チャネルの劣化
> （→ 縮んだ行動集合上での局所最適ロックイン）。（[正本 §5, §6 定理D](../docs/正本_ミクロ機構.md)）

### タスク・3チャネル・5条件
多腕：arm0=即時小（局所最適・t_change で価値↓）／ arm1=遅延大（大域最適・要探索＋遠視）／ distractor。
恐怖の3ノブ：**τ↓**（探索狭窄）・**k↑**（近視眼＝遅延報酬を割引）・**習慣↑**（価値と無関係に反復）。
5条件：calm / tau_only / k_only / habit_only / fearful（3つ全部）。

### 3チャネルを直交に読む指標
- explore（τ）＝標準価値ベクトルへの softmax 選択エントロピー（低τ→狭い）
- farsight（k）＝D(delay;k)=1/(1+k·delay)（直読）
- flexibility（習慣）＝価値と習慣が食い違う試行で「習慣に従わない」率

（生エントロピーは「良い腕への集中(良)」と「狭窄(悪)」を混同するため、τ は標準 landscape で直読する。）

## multiagent_fear_contagion.py — 多エージェント MA-1（恐怖伝播＝粛清カスケード）

> 多エージェント層の最初のプロトタイプ。層全体の設計は [docs/多エージェント設計.md](../docs/多エージェント設計.md)。

### 検証する主張（ロードマップ A-1 が多エージェントへ先送りした 定理D の「伝播」）
> 局所的な粛清（一部への統制不能な罰）が、直接罰を受けていないエージェントにもリスク回避（Ĝ↓・撤退）を
> 伝播させ、母集団規模の文化的萎縮を生む。tipping を超えると相転移的に全崩落。単一エージェントには無い創発。

### モデル（トーラス格子 24×24・4近傍・非対称結合）
- **Ĝ↓** ＝ 自分の罰（直接）／ より怖がる隣人の観察（vicarious・下方のみ・graded downhill）。
- **Ĝ↑** ＝ 自分の統制成功のみ（[§1](../docs/正本_ミクロ機構.md)：他者の成功は借りられない）。
- 崩落者も確率 `p_try` で再挑戦 → 統制可能なら回復（tipping の対抗力）。
- 粛清 ＝ 中央 6×6 patch に窓 [20,80) で統制不能罰。その後 環境は全員 統制可能へ戻る。

### 実行 / 出力（3枚）
```powershell
python sim/multiagent_fear_contagion.py
```
| ファイル | 何を示すか |
|---|---|
| `out/figMA1_cascade.png` | Ĝ 格子のスナップショット。中央粛清が放射状に広がり全崩落 |
| `out/figMA2_tipping.png` | 伝染強度 λ_obs → 最終崩落率の閾値曲線（文化的相転移） |
| `out/figMA3_vicarious.png` | 粛清シード vs 非シードの平均Ĝ（伝染 ON/OFF）。直接経験なしの崩落 |

### 結果（seed=20260604）
- **伝染 ON**：局所粛清 → **母集団 100% 崩落**。非シード（一度も罰されてない）も 0.74→**0.03**。
- **伝染 OFF**：非シードは無傷（→1.00）、粛清シードも撤退後に **回復**（→1.00）。
- → **崩落を母集団へ広げ・固定するのは伝染そのもの**（単一エージェントには無い創発現象）。
- tipping ≈ **λ_obs 0.35**：これを超えると相転移的に全崩落（文化的崖）。

### 次（[設計 §3](../docs/多エージェント設計.md)）
MA-2 社会的参照点（公平性）→ MA-3 方策模倣（規範）→ MA-4 (C,A) スイープで **5類型の創発的導出**。

## multiagent_social_reference.py — 多エージェント MA-2（社会的参照点＝公平性）

> 多エージェント層の2つ目の結合チャネル（[設計 §3](../docs/多エージェント設計.md)）。[§4 修正項2](../docs/正本_ミクロ機構.md) を集団へ。

### 検証する主張
> ρ_i = ω·E_self + (1−ω)·他者の結果。
> (1) **純粋な相対的剥奪**：不遇側の絶対報酬が変わらなくても、他者が厚遇されるだけで ρ↑ → R<ρ → κ倍損失 → 士気崩壊。

## multiagent_policy_imitation.py — 多エージェント MA-3（方策模倣＝規範・同調）

> 3つ目の結合チャネル（[設計 §3](../docs/多エージェント設計.md)）。Layer2 の「同調」ダイヤルの直接モデル化。

### 検証する主張
> 他者の選択（人気）を観察し模倣すると規範（共有方策）が創発する。だが同調が強すぎると、
> より良い選択肢があっても母集団は status quo にロックインし改善を採れない＝前例主義（アリ型・Stage5硬直）。
> 同調は両刃：強いほど合意は速いが、誤った規範に固着するリスクが上がる。

### モデル
`score_i[a] = V_i[a] + κ_conf·pop[a]`（個人価値 ＋ 人気バイアス）→ softmax 選択 → 個人RL更新。
全員 status quo(option0=1.0) から開始、option1=1.5 がより良いが探索して初めて分かる。

### 出力（3枚）
```powershell
python sim/multiagent_policy_imitation.py
```

|---|---|
| `out/figF1_norm_formation.png` | 最良採用率の時系列。低同調=移行、高同調=status quo 固着 |

### 結果（N=400, true_r=[1.0,1.5,0.6,0.6]）

- κ≈0.6–0.8 で相転移（真理追従 ⇄ 群れ）。

## multiagent_archetypes.py — 多エージェント MA-4（5類型の創発的導出・橋の完成）

> 3結合チャネルを統合した1つの population 模型。設計は [docs/多エージェント設計.md §4](../docs/多エージェント設計.md)。

### 検証する主張
> 経営者の (C,A) 設計＝ノブ (fear / f / kconf / ineq / omega / c) を変えると、5動物類型が
> 「安定した集団 regime」として創発し、[比喩 §2](../docs/比喩_5類型マクロ.md) の4軸署名と一致するか。
> 一致する範囲で、5類型は「対応表 → **導出**」へ格上げされる。

### 統一模型
各エージェント: morale/controllability M∈[floor,1]、option価値 V[K]。
M↑＝統制可能な成功（帰属ゲート）／ M↓＝統制不能罰（無力感）・相対的剥奪（κ・可視報酬で社会比較）・恐怖伝染。
choice = softmax(V + kconf·人気)/τ_eff（fear が τ を狭める）。

- ✅ **5類型とも互いに distinct** な regime として出て、比喩署名の主要点と一致。
- ⚠️ wolf の consensus は高い（予測 low）＝**最良への集中**（同調でなく個人学習で全員が同じ最良へ）。良性のズレ。
- ⚠️ chimp の「分断」を出すには社会比較を **可視報酬(ext)基準** にする必要があった（恐怖の罰が参照点を下げると剥奪が相殺される、という統合上の発見）。

- → 「(C,A) から5 regime が創発」は **プリセット5点で成立**。盲目的クラスタリングで丁度5個出る、とは主張しない（誇張回避＝§0）。

## multiagent_rewilding.py — 多エージェント MA-5（再野生化＝Stage5 硬直からの集団脱出）

> MA-4 の後続。[橋渡し](../docs/橋渡し_対応表.md)「Stage5硬直＝定理B 無力感アトラクタ／再野生化＝唯一の脱出」を集団で実証。Layer2「再野生化」の形式化。

### 検証する主張
> 硬直 ant/Stage5 集団（高 kconf・status quo 固着）は、より良い option1 が在っても人気バイアスで離陸できない（前例ロックイン）。
> 脱出は同調を緩める「強さ」でなく「前例の届かない場所（autonomy を保った隔離細胞）」を作れるかで決まる。
> ＝定理B「外生注入だけが無力感アトラクタの脱出路」の集団版。通俗版（"号令で変えろ"＝全体微緩）と分岐する非自明な帰結。

### モデル（MA-3 の人気バイアス ＋ 個人RL ＋ 観察的価値学習[実績デモ]）
- choice = softmax((V_i + kconf·人気)/τ)、個人RL `V←V+η(報酬−V)`（MA-3 と同型）。
- **実績デモ**：ある option を「臨界質量 `vis_thresh` 以上」が **commons 上で**実践して初めて見える手本になり、結合者が実現 payoff へ V を寄せる（同調＝人気 とは別チャネル＝実績の伝播）。
- **隔離細胞**：隔離窓 `[0,t_recouple)` は commons から遮断（多数派に**見えず**・多数派も**見ない**＝skunkworks）。低 kconf で option1 を個人学習。再結合後 **autonomy 保持**なら低 kconf のまま／**再吸収**なら多数派の高 kconf へ戻る。

### 実行 / 出力（3枚）
```powershell
python sim/multiagent_rewilding.py
```
| ファイル | 何を示すか |
|---|---|
| `out/figH1_rewilding.png` | adoption 時系列。放置=0 ／ 再野生化(autonomy)=再結合後にカスケードで反転 ／ 再吸収=再結合で崩落（飲まれる） |
| `out/figH2_isolation_threshold.png` | 隔離サイズ→最終adoption。autonomy は閾値超で脱出／再吸収は離陸しない |
| `out/figH3_phase.png` | 相図（多数派 kconf × 隔離サイズ）。脱出領域＝低同調 **または** 大きな保護細胞 |

### 結果（seed=20260604）
- 放置 **0.00** ／ 再野生化(autonomy) **0.94**（majority 1.00）／ 再吸収 **0.00**（飲まれて離陸しない）。
- 通俗版対照（細胞なし・同調だけ操作）：放置 0.00 ／ 全体微緩(kconf=nudge) 0.00 ／ 全廃(kconf=0) 0.81。＝**号令で緩めるだけでは解けない**（全廃は効くが大規模で非現実的）。
- 脱出閾値（autonomy・最終adoption>0.5 の最小隔離サイズ）≈ **0.30**。脱出領域 面積比 **0.79**。

### §0 正直な照合
- ✅ 放置／全体微緩では status quo ロックが解けない。autonomy を保った臨界質量の隔離細胞でのみ規範が反転。
- ✅ 再吸収（細胞を多数派の同調へ戻す）と人気に飲まれ元へ戻る＝**autonomy が要石**。
- ⚠️ 万能ではない：細胞が小さい／多数派の同調が強いと脱出しない（fig2/fig3 の閾値）。token な skunkworks（数%）では足りず臨界質量が要る。

### 非目標
実データへの係数フィットをしない（[§0](../docs/正本_ミクロ機構.md)）。1機構（再野生化＝autonomy 隔離細胞）の検証であって、再野生化の唯一解性を実データで主張するものではない。

## multiagent_dunbar.py — 多エージェント MA-6（規模＝Dunbar 壁）

> [比喩](../docs/比喩_5類型マクロ.md)「Dunbar 壁」と「100人超で自然発生する権力ゲーム（chimp）」の形式化。規模そのものが regime を変えることを示す。

### 検証する主張
> 有界な社交容量 D（各自が信頼／監視できる相手の上限）があると、集団規模 N が増えるほど
> 評判被覆 coverage=min(1, D/(N-1)) が下がる。監視外では裏切りが罰されず、N が壁を超えると
> 協力（cohesion）が**相転移的に崩落**する。＝「人を増やしても管理職を足せば回る」式の通俗版と分岐。
> 崩落は連続的希薄化でなく鋭い壁（条件付き協力の高位アトラクタが鞍点分岐で消える）。
> 壁の位置は普遍数でなく容量 D に比例する（§0：「150」は人の容量推定であって普遍定数でない）。

### モデル（条件付き協力＝reciprocity のネットワーク閾値ダイナミクス）
- 各自は D 人の acquaintance を監視。`p_acq_i` = acquaintance の協力率。
- 次期の協力確率 = `coverage · σ(β(p_acq_i − θ))`。coverage が「評判が効く割合」。
- N≤D で coverage=1（小集団は全員監視＝cohesive）。N≫D で coverage→小 → 高位アトラクタ消失 → 崩落。

### 実行 / 出力（3枚）
```powershell
python sim/multiagent_dunbar.py
```
| ファイル | 何を示すか |
|---|---|
| `out/figI1_size_timeseries.png` | 協力率の時系列。小集団は cohesive を維持／大集団は同じ規則でも崩落 |
| `out/figI2_dunbar_wall.png` | 規模 N → cohesion・最大協力クラスタが壁で急落（coverage は滑らかなのに cohesion は鋭い崖）。断片化 |
| `out/figI3_wall_scales_with_D.png` | 壁の位置が容量 D に比例（普遍数でない） |

### 結果（seed=20260604, D=40）
- N=20 cohesion **0.995**（cohesive）／ N=70 **0.04**・N=250 **0.01**（崩落）。
- **Dunbar 壁 ≈ N=55**（N=45→0.89 が N=55→0.04 へ急落＝鋭い相転移）。最大協力クラスタも同時に消失＝断片化。
- 壁 × 容量：D=20→35 / 40→55 / 60→86 / 80→116 ＝ **壁は D に比例**（≈1.4D・普遍定数でない）。

### §0 正直な照合
- ✅ 同じ施策でも規模が壁を超えると cohesion が崩落（規模そのものが regime を変える）。
- ✅ 崩落は鋭い相転移（高位アトラクタの鞍点分岐）。coverage の滑らかな低下と対照的。
- ✅ 壁は容量 D に比例＝「150」は人の容量推定であって普遍定数でない。
- ⚠️ 崩落後の「分断・政治(chimp)」は giant component の消失として示すが、faction の内容や権力ゲームの詳細はモデル化していない（過剰主張しない）。

### 非目標
実データへの係数フィットをしない（[§0](../docs/正本_ミクロ機構.md)）。1機構（有界容量による評判被覆の崩壊）の検証であって、特定組織の「最適規模」を主張するものではない。

## multiagent_hierarchy.py — 多エージェント MA-7（階層別最適化＝層ごとに別 regime）

> [比喩 §5](../docs/比喩_5類型マクロ.md)「同じ会社でも層で最適な生き物は違う」と[橋渡し](../docs/橋渡し_対応表.md)の階層別を形式化。

### 検証する主張
> 層ごとに『タスク』が違うので最適 regime も違う：現場（floor）＝探索（低同調=wolf が最適）、
> 管理（body）＝調整・整列（高同調=ant が最適）。経営（exec）＝この architecture（各層の同調と
> 層間結合 λ）を設計する層。org 性能 P = 現場探索 E × 管理調整 Co。
> 通俗版「全社を1つの型で揃える」と分岐：(1) 一律 regime は必ず片層を犠牲にし劣る、
> (2) 最適は差別化＝(c_F,c_B) の対角線(一律)でなく off-diagonal、
> (3) ただし結合 λ が強い（管理の同調が現場へ漏れ＝process 押し付け）と現場の探索が死に P 崩落
> ＝現場の autonomy が要る（MA-5 と連結）。

### モデル
- **現場（探索）**: status quo から探索。`choice=softmax((V+c_F_eff·人気)/τ)`＋個人RL。E=最良 practice 採用率。`c_F_eff = c_F + λ·c_B`（top-down の process 圧）。
- **管理下の本体（調整）**: 等価な K 規約の調整ゲーム（報酬＝自分と同じ選択の割合）。多様から出発し、同調 c_B が高いほど整列（Co=合意=最大シェア）。

### 実行 / 出力（3枚）
```powershell
python sim/multiagent_hierarchy.py
```
| ファイル | 何を示すか |
|---|---|
| `out/figJ1_architectures.png` | 4アーキテクチャの E/Co/P。一律 wolf=調整欠・一律 ant=探索欠・差別化+loose=両立・差別化+tight=現場死 |
| `out/figJ2_differentiation.png` | (c_F×c_B) 相図。最適は対角線(一律)でなく off-diagonal（現場低×管理高） |
| `out/figJ3_coupling_autonomy.png` | 結合 λ→現場探索 E と P。強い結合で崩落＝現場の autonomy が要る |

### 結果（seed=20260604）
- 4アーキテクチャ P：一律 wolf **0.21**（Co欠）／一律 ant **0.00**（E欠）／**差別化+loose 0.47**（最良）／差別化+tight **0.00**（現場官僚化）。
- 相図：最適 **P=0.80 @ 現場c_F=0・管理c_B≈2.8**（off-diagonal）。一律(対角)最良 0.21 → 差別化が **+0.60** 上回る。
- 結合：λ=0 で E=0.76 → λ=1.5 で E=0.00（現場探索が崩落）。

### §0 正直な照合
- ✅ 一律 regime（全 wolf/全 ant）は片層を犠牲にし劣る（層でタスクが違う）。
- ✅ 最適は差別化＝対角線(一律)でなく off-diagonal。
- ✅ 強い top-down 結合は現場の探索を殺す＝現場の autonomy が要る（MA-5 と連結）。
- ⚠️ P=E×Co は層タスクの最小モデル。faction／権力や経営層の意思決定の中身は非モデル化（過剰主張しない）。

### 非目標
実データへの係数フィットをしない（[§0](../docs/正本_ミクロ機構.md)）。層タスクの最小モデルであって、特定企業の「最適な階層設計」を主張するものではない。
