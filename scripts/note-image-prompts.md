## 共通スタイル（各シーン文の末尾に必ず付ける）
```

```
注：動物福祉上きわどい実験（learned helplessness 等）は、残酷描写を避け象徴的に表現する方針。

## 使い方
1. 各行の **シーン文** + 上の **共通スタイル** を連結して画像生成AIに渡す。
2. 生成画像を `note-images/<slug>.png` として保存（gitignore対象）。
3. note 投稿時にアイキャッチとしてアップロード（タイトルは `note-export/<slug>.md` の1行目を使用）。
4. ¥0で軽く済ませたい記事は `scripts/gen-note-images.mjs`（絵文字SVGカード・Chrome直叩き）でも生成可。
