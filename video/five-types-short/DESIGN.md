# DESIGN — 組織の5類型（縦型9:16ショート・第2作）

サイト「動物から組織を読む」と同一トンマナ（第1作と共通）。落ち着いた知的トーン＋5類型紹介はテンポよく。

## Style Prompt
深緑×クリームの自然なパレット。フラットなSVGの動物キャラ5体（オオカミ／アリ／チンパン／ボノボ／ハイエナ）が次々登場。背景クリーム、文字は濃い緑墨、アクセント森林の深緑、強調は土オレンジ。ゴシック太字。装飾最小・余白広め。縦型なのでテロップ大きくリズムよく。

## Colors
- `#faf8f4` 背景 / `#1d2321` 文字 / `#2f6f4f` アクセント(深緑・ブランド核) / `#e6efe9` 淡緑 / `#6b7370` 補助 / `#e3e0d8` 罫線 / `#d9893b` 強調(要所のみ)

## Typography
- `"Noto Sans JP", sans-serif`（hyperframes対応確認済）
- 見出し/型名: 900・縦型大きめ / 本文: 600 / weight差でメリハリ

## Motion
- 各類型をテンポよく登場（entrance）。`power3.out`/`back.out`/`expo.out` を混ぜる。
- キャラは軽い呼吸。トランジションはクロスフェード＋slide。

## キャラ色分け（5体を見分ける）
- オオカミ=青灰`#8a97a5`(精悍・シャープ) / アリ=赤茶黒`#6b3a २a`(働き者) / チンパン=肌茶`#a9774e`(やや厳つい) / ボノボ=黒顔+メガネ`#3a322e`(賢者) / ハイエナ=茶`#c4b095`(だらっと)

## What NOT to Do
- 原色べた塗り・ネオン → 知的トーンを壊す
- 暗黒背景 → クリーム維持 / 明朝体 → ゴシック統一
- §0違反（「うちは○○型」と断定）→ 「比喩・レンズ」と明示、純血種は存在しないスタンス維持
