# YouTube Shorts 投稿用メタデータ（縦型9:16・45秒ショート 全21本）

> 「動物実験から学ぶマネジメント理論」シリーズの縦型ショート動画の、投稿用メタ情報（タイトル／説明文／タグ）一括集。各動画は元記事を45秒の「動物キャラ寸劇」に要約したもの。

## 使い方（運用メモ）

- **コピペ用**：各動画ブロックのタイトル／説明文／タグをそのまま YouTube Studio の各欄へ貼る。
- **公開は手動**：自動公開しない。アップロードは下書き（非公開）→ 人の目で確認 → 公開。
- **投稿ペース**：1日数本を目安に分散（一気に大量投稿しない）。
- **noteリンクは人間が追記**：概要欄末尾に note メンバーシップ等の導線を足す場合は、投稿時に人間が手で追記する（このファイルには含めない）。
- **タイトルは40字以内＋末尾に半角スペース＋`#Shorts`**。動物名入り・フック重視。
- **§0スタンス厳守**：効果は保証しない。「比喩／レンズ」と明示し、生物学そのものでなく「組織を読むための比喩」として淡々と提示する。誇張・断定は避ける。
- 記事リンクは GitHub Pages（`https://zumenseki.github.io/doubutsu-soshikiron/articles/<slug>/`）。サイト公開停止時はリンクを差し替えること。

人は最悪の底ではじっと耐え、状況が少し良くなった後の反転で動く。逃げられない電撃を受け続けた犬は逃げられる状況でも逃げない（学習性無力感）。耐える人々を動かすのは、より深い苦しみでなく「勝てる」という証拠だ。恐怖は安く、勇気は高く伝わる。
