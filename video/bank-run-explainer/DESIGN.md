# DESIGN — 取り付け騒ぎ／恐怖伝播（横型16:9・YouTube解説・約3.4分・TTSナレ付き 第7作）

横型解説系統の第7作。応用シリーズ（ドメイン外の一致）。1作目 five-types-explainer と同一トンマナ・同一パイプライン。テーマは「健全な銀行でも"皆が引き出す"と皆が思えば倒れる」＝恐怖伝播の自己成就（Diamond-Dybvig 1983）。**第4作（恐怖⇄学習）・第5作（締め出しの伝播vs置換）で触れた"伝播"の集団版＝伏線回収**。

## 資産流用元
- **bankrun-short（縦型）から全資産コピー**：銀行SVG（深緑・¥）／2均衡カード（健全/崩壊）／恐怖伝播ドミノ（!付きアリ6体・staggerカスケード）／取り付けvs蜂起の符号違いカード／盾SVG（預金保険）。縦型shortの完成資産をそのまま横型レイアウトに展開＝工数軽。

## Format
- 1920×1080（16:9）・約205秒（3分25秒）・**24fps**・5シーン
- ⚠️**24fpsは意図的**：長尺（205s）×空きRAM逼迫時に30fpsだと frame~5462(182s)で `Target closed` メモリクラッシュ（第6作で確立した落とし穴）。総フレームを壁未満に下げる回避策。24fps＝解説動画として十分・映画標準。
- 音声：Edge TTS `ja-JP-NanamiNeural --rate=+10%`（narration/ch1-5.mp3・track1直列）＋BGM（bgm.mp3=procrastination bgm-calm ループ・volume0.22・track0）。**mp3直使用必須**（wav化でload timeout）。
- 字幕：edge-tts SRT→章オフセットシフトの GROUPS（40cue）・一度に1グループ・hard kill
- 章オフセット：ch1=1.0 / ch2=32.68 / ch3=69.55 / ch4=112.8 / ch5=156.37（章間 約2.5秒の「間」）

## Motion / §0
- シーン遷移＝クロスフェード＋content y:60→0。entrance のみ・SRT実測cueに同期
- S3 伝播ドミノ＝アリ6体を stagger で出し、!（bang）を左から順にカスケード点灯（恐怖の連鎖を動きで表現・縦型shortの演出を踏襲）
- §0：bank-run は応用（ドメイン外の一致）。Diamond-Dybvig は金融理論の引用、動物の恐怖伝播との一致は「機構の到達域を示す傍証」。末尾注で「協調失敗の均衡として読むレンズであり個別破綻の単一原因断定でない」を必守（記事§0踏襲）

## What NOT to Do
- 原色べた塗り・ネオン／暗黒背景／明朝体
- 特定銀行の破綻を「この機構が原因」と断定（§0違反）／SVBを名指しで断罪
- 字幕ゾーン（下部185px）にコンテンツを進入させる
- GSAP `attr:{class}`/`textContent` のアニメート（第6作でレンダ即死・opacityクロスフェードで代替）
