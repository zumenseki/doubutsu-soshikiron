# DESIGN — 公平性／不公平の非対称コスト（横型16:9・YouTube解説・約3.5分・TTSナレ付き 第6作）

横型解説系統の第6作。理論核シリーズ。1作目 five-types-explainer と同一トンマナ・同一パイプライン（Edge TTSナレ＋SRT同期字幕）。テーマは「同じ総額でも不公平は組織を壊す」＝報酬は絶対額でなく社会的参照点からの差で感じる（Brosnan & de Waal 2003 オマキザルのブドウ/キュウリ実験）。

## 新規資産
- **カプチン猿（オマキザル）SVG**：本作で新規作成。チンパンSVG（five-types-explainer S5）をベースに、capuchinの特徴＝小顔・頭頂が明るい毛冠（`path` の淡色冠）・茶系。S1単体＋S2で2匹（キュウリ側/ブドウ側）。
- S2の演出：隣がブドウをもらった瞬間（46.61s）、キュウリ猿の state を「満足（緑）→拒否！（橙）」に GSAP `textContent`/`attr:{class}` で変化＋本体を震わせる（`x` 往復）＝実験の核を動きで見せる。

## Format
- 1920×1080（16:9）・約211秒（3分31秒）・30fps・5シーン
- 音声：Edge TTS `ja-JP-NanamiNeural --rate=+10%`（narration/ch1-5.mp3・track1直列）＋BGM小音量（bgm.mp3=procrastination-short/bgm-calm ループ・volume0.22・track0）
- ⚠️音声は**mp3直使用**（wav化すると page load 10s timeout で inspect/render 不能）
- 字幕：edge-tts SRT（文単位）を章オフセットでシフトした GROUPS 配列（44cue）・一度に1グループ・hard kill
- 章オフセット：ch1=1.0 / ch2=33.84 / ch3=71.16 / ch4=117.15 / ch5=159.1（章間 約2.5秒の「間」）

## Motion / §0
- シーン遷移＝クロスフェード＋content y:60→0。entrance のみ（最終シーン以外 exit 禁止）・SRT実測cueに同期
- S3 士気グラフ＝`strokeDasharray/Dashoffset` で右下がりを描画（ナレ「単調に下がりました」95.25s に同期）
- §0：unfairness-cost は Layer1正本寄り（参照点κ・損失回避は機構）。オマキザル実験は史実の引用。チンパン型（100人超で政治化）は Layer2比喩。末尾注で「機構を表す式であって特定組織のデータ分析ではない」を必守

## What NOT to Do
- 原色べた塗り・ネオン／暗黒背景／明朝体
- オマキザル実験を「組織はこうなると断定」に見せる（§0違反）／効果保証／特定企業名指し（記事の"ある会社"を固有名にしない）
- 字幕ゾーン（下部185px）にコンテンツを進入させる
