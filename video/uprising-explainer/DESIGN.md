# DESIGN — 蜂起／なぜ人は耐え、ある日いっせいに立つのか（横型16:9・YouTube解説・約3.8分・TTSナレ付き 第8作）

横型解説系統の第8作。応用シリーズ（ドメイン外の一致）。**第7作 bank-run（取り付け騒ぎ）の完全な鏡像**＝対構造の完成。テーマは「耐える→突然いっせいに立つ」を3機構の収束（consilience）で読む。

## bank-run（第7作）との鏡像構造
- bank-run＝恐怖伝播（崩壊・突発・無条件に伝わる）／uprising＝勇気伝播（蜂起・稀・自己効力感を掛けて初めて）
- 同じ伝播ドミノでも、bank-runは「!（恐怖）」橙カスケード、uprisingは「↑（拳）」緑カスケード＝符号違いを視覚で対比
- S4で両者の非対称を明示（恐怖は安く・勇気は高い）＝第7作を見た視聴者に対の閉じを与える

## 資産流用元
- **uprising-short（縦型）から全資産コピー**：群衆アリ（灰色=無力/茶色=蜂起の2色）／うなだれイヌSVG（学習性無力感）／J字曲線（curveJ・spark付き）／勇気カスケード（↑fist）。
- ⚠️spark円は short の `attr:{r:0→16}` を避け、**半径15固定＋`transform-box:fill-box`でscale出現**に変更（第6作のGSAP属性アニメ起因クラッシュを予防）。

## Format
- 1920×1080（16:9）・約225秒（3分45秒）・**24fps**（長尺メモリ壁回避・第6作の知見）・5シーン
- 音声：Edge TTS `ja-JP-NanamiNeural --rate=+10%`（ch1-5.mp3・track1直列）＋BGM（bgm.mp3=procrastination bgm-calm ループ・volume0.22・track0）。**mp3直使用**。
- 字幕：edge-tts SRT→章オフセットシフトの GROUPS（38cue）・一度に1グループ・hard kill
- 章オフセット：ch1=1.0 / ch2=36.36 / ch3=77.28 / ch4=119.45 / ch5=166.04（章間 約2.5秒の「間」）

## Colors / Typography
- `#faf8f4` 背景 / `#1d2321` 文字 / `#2f6f4f` 緑(勇気・蜂起・統制可能側＝本作の主色) / `#d9893b` オレンジ(恐怖・損失・無力側) / `#e6efe9` 淡緑 / `#6b7370` 補助 / `#e3e0d8` 罫線
- bank-runは橙主軸（恐怖）、uprisingは緑主軸（勇気）＝鏡像を色でも表現
- `"Noto Sans JP", sans-serif`・見出し900 / 本文700 / 字幕700・40px

## Motion / §0
- シーン遷移＝クロスフェード＋content y:60→0。entrance のみ・SRT実測cueに同期
- S2 J字曲線＝`strokeDasharray/Dashoffset` で描画→spark出現（統制可能と気づく瞬間）
- S4 勇気カスケード＝アリ6体を stagger、↑（拳）を左から順にカスケード点灯（bank-runの!カスケードと対）
- §0：uprising は応用（consilience）。3機構（学習性無力感/損失回避/選好カスケード）は別経路の独立理論で、一点収束が「機構の到達域を示す傍証」。末尾注で「機構を歴史の集団行動に当てるレンズで各事象の単一原因断定でない」を必守（記事§0踏襲）

## What NOT to Do
- 原色べた塗り・ネオン／暗黒背景／明朝体
- 特定の革命/政変を「この機構が原因」と断定（§0違反）／東欧1989を単一原因化
- 字幕ゾーン（下部185px）にコンテンツを進入させる
- GSAP `attr:{r}`/`attr:{class}`/`textContent` のアニメート（クラッシュ予防・scale/opacityで代替）
