# DESIGN — 現場どうぶつ診断 コンテスト提出デモ動画 v1（横型16:9・約2分54秒・TTSナレ付き）

横型解説系統と同一トンマナ・同一パイプライン（Edge TTSナレ＋SRT同期字幕）。ただし本作は**記事解説でなく「プロダクトのデモ」**＝実プロダクト `/shindan` の実画面スクショ3枚を背景カードに据える点が固有。狙い＝「便利ツールで終わらせず売上線まで引いた」を3軸（自律性／事業性／反応）で見せる（台本＝docs/デモ動画台本.md・§17照合済）。

## Format
- 1920×1080（16:9）・**約174秒（2分54秒）**・30fps・7シーン
- 音声：Edge TTS `ja-JP-NanamiNeural --rate=+10%`（narration/ch1-7.mp3・track1直列）＋BGM小音量（bgm.mp3＝controllability-explainer のループ流用・volume0.22・track0）
- ⚠️音声は**mp3直使用**（wav化すると page load 10s timeout で inspect/render 不能）
- 字幕：edge-tts SRT（文単位）を章オフセットでシフトした GROUPS 配列（38cue）・一度に1グループ・hard kill
- 章オフセット：ch1=1.0 / ch2=24.86 / ch3=53.12 / ch4=86.03 / ch5=106.99 / ch6=128.46 / ch7=149.82（章間 約2.0秒の「間」）

## Colors / Typography（横型系統共通）
- `#faf8f4` 背景 / `#1d2321` 文字 / `#2f6f4f` 緑(自動・無料・ポジ側) / `#d9893b` オレンジ(人を残す・危険・強調＝アクセント) / `#e6efe9` 淡緑 / `#6b7370` 補助 / `#e3e0d8` 罫線 / endcard地 `#1d2321`＋`#8fd0ac`
- `"Noto Sans JP", sans-serif`（Serif/mono 不可）・見出し900 / 本文600-800 / 字幕700・40px
- 実画面は**ブラウザ風カード**（白地・上バー3ドット＋URL・角丸18px・影）に img幅1180で内包

## Motion / §0
- シーン遷移＝クロスフェード＋content y:60→0。entrance のみ（最終シーン以外 exit 禁止）・SRT実測cueに同期
- 実画面カードは scale0.95→1＋opacity で「立ち上がる」入場。S4/S6 は左右/下からの段階入場
- §0必守：S7末で「式で機構を表したもので組織データで係数を当てたモデルでない＝仮説生成ツール」を明示。S6 反応は**直送未実施につき数字は「◯件・現在進行中」**＝0を盛らない（§0と一貫）。型（恐怖ハイエナ）は「たとえば」と例示・断定しない

## What NOT to Do
- 原色べた塗り・ネオン／暗黒背景（endcard濃色地は可）／明朝体
- 反応の数字を実績ゼロなのに「達成」風に見せる（§0違反）／効果保証
- 字幕ゾーン（下部185px）にコンテンツを進入させる
- 実画面スクショの改変（実プロダクトの本物画面である担保を崩さない）
