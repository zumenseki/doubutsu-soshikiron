# DESIGN — 不公平のコスト（縦型9:16ショート・第3作）

第1/2作と同一トンマナ（深緑×クリーム・Noto Sans JP・知的）。内容は「公平・損失・怒り」寄りなので落ち着き版BGM。

## Colors
- `#faf8f4` 背景 / `#1d2321` 文字 / `#2f6f4f` アクセント / `#e6efe9` 淡緑 / `#6b7370` 補助 / `#e3e0d8` 罫線 / `#d9893b` 強調（怒り/損失の要所）

## Typography
- `"Noto Sans JP", sans-serif` / 見出し900 / 本文600 / weight差でメリハリ

## キャラ・小物
- **オマキザル**（新規）: 茶顔＋クリーム色の顔まわり、満足顔↔怒り顔の2表情
- キュウリ＝緑`#7faf4a` / ブドウ＝紫`#7a4fa0`（報酬の格差を色で）
- 天秤＝満足＜不満（損失回避の可視化）
- **チンパン**＝第2作SVG流用（説明可能性＝政治の火種シーン）

## Motion
- 投げ返す瞬間に強い動き（怒り）。他は落ち着いた entrance。`back.out`/`power3.out`混在。
