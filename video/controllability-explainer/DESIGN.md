# DESIGN — 統制可能性／学習性無力感（横型16:9・YouTube解説・約3分・TTSナレ付き 第4作）

横型解説系統の第4作。1作目 five-types-explainer と同一トンマナ・同一パイプライン（Edge TTSナレ＋SRT同期字幕）。fear-explainer（恐怖⇄学習）の姉妹編で、恐怖の機構をミクロに掘る。テーマは「罰が効くかは"強さ"でなく"避けられるか（統制可能性）"で決まる」。

## Format
- 1920×1080（16:9）・約174秒（2分54秒）・30fps・5シーン
- 音声：Edge TTS `ja-JP-NanamiNeural --rate=+10%`（narration/ch1-5.mp3・track1直列）＋BGM小音量（bgm.mp3=procrastination-short/bgm-calm ループ・volume0.22・track0）
- ⚠️音声は**mp3直使用**（wav化すると page load 10s timeout で inspect/render 不能）
- 字幕：edge-tts SRT（文単位）を章オフセットでシフトした GROUPS 配列（38cue）・一度に1グループ・hard kill
- 章オフセット：ch1=1.0 / ch2=24.48 / ch3=62.93 / ch4=99.05 / ch5=135.1（章間 約2.5秒の「間」）

## シーン構成
| S | 内容 | 主資産 |
|---|---|---|
| S1 | フック「効くのは"厳しさ"ではない／決め手は避けられるか」 | オオカミ（罰・恐怖の象徴／イヌ科で犬実験に近い） |
| S2 | セリグマン&マイヤー1967＝同強度・同回数のショック、違いは統制可能性の1点だけ→質的分岐 | 2群対比（雷⚡3／回避学習[緑] vs 学習性無力感[橙]） |
| S3 | 組織への翻訳＝同じ叱責でも統制可能（改善路）→適応 vs 統制不能（理不尽・恣意的）→無力感 | フォーク図（同じ叱責→2分岐） |
| S4 | 非自明予測＝連続でなく質的不連続／自己封止で自然回復しない／外生注入でのみ脱出 | 階段グラフ（崩落[橙]→崖→適応[緑]・なめらか期待線は点線）＋3点 |
| S5 | 恐怖の正当域＝4条件すべて重なる狭域／知識労働は外側＋§0＋CTA | 4条件グリッド |

## Colors / Typography
- `#faf8f4` 背景 / `#1d2321` 文字 / `#2f6f4f` 緑(統制可能・適応・脱出側) / `#d9893b` オレンジ(罰・統制不能・崩落側＝本作の主アクセント) / `#e6efe9` 淡緑 / `#6b7370` 補助 / `#e3e0d8` 罫線
- `"Noto Sans JP", sans-serif`（Serif不可）・見出し900 / 本文700 / 字幕700・40px

## Motion / §0
- シーン遷移＝クロスフェード＋content y:60→0。entrance のみ（最終シーン以外 exit 禁止）・SRT実測cueに同期
- S4 階段グラフ＝`strokeDasharray/Dashoffset` で描画アニメ（ナレ「質的に不連続な分岐」106.53s に低位→崖→高位を順に描く）。なめらかな期待線（点線）を先に引いて「連続でない」を対比表現
- §0：controllability は Layer1正本寄り（比喩でなく機構）。セリグマン犬実験は史実の引用だが、組織への適用は「理論の型が見える」位置づけ。末尾注記で「式で機構を表したもので組織データで係数を当てたモデルではない」を必守

## What NOT to Do
- 原色べた塗り・ネオン／暗黒背景／明朝体
- セリグマン実験を「組織はこうなると断定」に見せる（§0違反）／効果保証
- 字幕ゾーン（下部185px）にコンテンツを進入させる
